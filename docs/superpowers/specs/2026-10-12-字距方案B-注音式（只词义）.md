# ① 字距问题 · 方案 B「注音式（只词义）」开发交接单（2026-10-12 用户已选定）

> 用户原话：「1. 目前文章内的英文和中文，会突然增加字节距」→ 三案（关词义/只音标/不改）被否
> （「不能去」行内词义）→ 2026-10-12 第二轮出 A/B/C 三新案实景对照，**用户选定 B**。

## 1. 问题与实测（开发前必读）

- **病根**：桌面档 `.sec .para` 是 `text-align: justify`；行内小字块 `.gl`（`/音标/ 词义`，`white-space: nowrap`，
  宽 30~200px）不可断行 → 含长小字的行被 justify 拉出**巨大词间空格：实测最大 48.1px（900px 档）／54px（720px 档）**，
  正常词距 ≈ 4.7px（10 倍级）。窗口越窄越凶。
- **手机档**本就左对齐、无拉缝（实测各案均 4.5px）——手机档毛病只是「长小字块整块顶行、行末参差」。
- 对照实景：`work/gl5_compare_desktop.png` / `work/gl5_compare_mobile.png`（四行 = 现状/A/B/C），
  单图 `work/gl5_v2_*.png` 就是**本方案 B** 的定稿观感；预览工具 `work/gl5-shots.cjs`（含 B 的 CSS、夹紧演示）。

## 2. 方案 B 定稿形态（照此实现）

1. **小字从「贴词后」改为「悬词上」**：每个目标词正上方挂一小行**词义**（10.5px，`var(--muted)`，居中）；
   **音标从注音里去掉**（点词弹层 / 词卡里照旧有）。
2. **正文彻底不占行宽**：`.gl` 绝对定位；`text-align: left`（两档都去 justify）；
   行距放宽给注音留行间：`.sec .para` `line-height ≈ 2.35`（两档统一，视觉以 `work/gl5_v2_*.png` 为准）。
3. **注音夹紧**：注音居中展开，行首/行尾词会越出栏口（实测 `mantle` 注音被裁左半）——
   渲染后量一次 rect，超出 `para` 左右边就往栏内推（非逐帧；resize / 字体就绪后重跑一次即可）。
   B 案注音短（≈≤7 字），夹紧命中率低，但必须有。

## 3. 实现清单（改 `index.html`，坑都踩过）

- **`wrapWords`（≈3684 行）**：输出从 `<span class="w">词</span><span class="gl">…</span>`
  改为 **加一层定位壳**：`<span class="wg"><span class="w">词</span><span class="gl">…</span></span>`。
  （`.gl` 是 `.w` 的**兄弟**，纯 CSS 定位不到词——必须包壳；预览脚本里同款 JS 包壳已验证。）
- **CSS**（作用域**收在 `.sec`**，别动 `#lcMini` 随身听字幕窗，它行体复用 `.gl`、尺寸另有覆写）：
  ```
  .sec .wg { position: relative; }
  .sec .gl { position: absolute; left: 50%; bottom: calc(100% + 3px); transform: translateX(-50%);
             margin: 0; font-size: 10.5px; line-height: 1.1; white-space: nowrap;
             pointer-events: none; }
  .sec .gl-p { display: none; }          /* 音标不进注音（弹层里照旧） */
  .sec .para { text-align: left; line-height: 2.35; }
  ```
  `body.hide-gl .gl { display:none }` 既有开关保持生效；dark 下 `.gl` 颜色走既有 `body.dark .gl`。
- **`refreshGloss`（≈3672 行）**：用 `el.nextElementSibling` 找 `.gl`——包壳后 `.gl` 仍是 `.w` 的
  next sibling（壳内相邻），这条**不用改**，但要实测确认。
- **`elContext`（≈3655 行）**：**必须改**。现在按 `.sent` 直接子节点扫、遇 `el` break；包壳后
  `el` 不再是 `.sent` 的直接子节点 → 永远 break 不了、上下文全错（影响按句选义项的小字内容）。
  建议改成**文本节点遍历**：跳过 `.gl` 子树，按「进入 `el` 前 / 离开 `el` 后」收 out/tail。
- **别忘**：A-B 循环标记 `.sent.ab-a::after`（top:-10px）可能与首行注音重叠——开发时截图查一下。
  （**已闭环**：实测确有重叠，修法与验证见 §6「AB 交互面」。）

**AB 交互面 × 注音（§3「别忘」闭环，开发期实测后修复）**：

- **徽标重叠**（实锤）：`.sent.ab-a/.ab-b::after` 挂句子首行左缘（`left:-4px`、宽 22px、`top:-10px`）；
  句首词注音居中展开后左端会伸进徽标区——「Spring」样本实测 **14×8px 真实重叠**（注音「v. 跳；n. 春天」
  左端被 A 徽标压住）。几何规律：首行位置两者 y 必重叠 8px → x 相交即真重叠；危险线 = 注音宽 ≳ 词宽 − 28。
- **区间框穿字**（推演+实测）：`#abRegion` 上边框（`top − 6` 起、2px）横穿 A 句首行注音带（注音悬句子上方 ~14px）。
- **修法**：`clampGloss` 对带 `ab-a/ab-b` 的句子把相交注音下限抬到「徽标右缘 + 4px」；`updateABRegion` 顶边在
  A 句首行带注音时抬到注音上方 4px（`padTop` 动态）；两条链由 `paintAB()` 末尾 `scheduleClampGloss()` 驱动
  （标记加/去都重算，去标记自然归零）。
- **反向验证**（逐条禁用后跑锁）：禁 clampGloss 让位 → `shifted` 停在 0px 红；禁 region 让位 → `regionCross=true` 红。
  恢复后 diff 逐字节 SAME。
- **回归锁**：`gloss-annot.spec.ts` 用例 6「AB 徽标让位」（真实链路 toggleAB→abTap 设 A → 断言不重叠 + gap ≥ 4px
  → 续设 B → 断言区间框不穿注音 → 取消 → 断言归位 0px）。
