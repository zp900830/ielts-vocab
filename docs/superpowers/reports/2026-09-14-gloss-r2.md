# Gloss R2 行为变更说明（行内取前两义）

- 日期：2026-09-14
- 范围：`shadow/index.html` `glossParts`（行内 gloss 释义截取规则）
- 状态：待用户签字

## 变更前（R1 / 旧规则）

行内 gloss 只取首义并截断到 12 字：

```js
const m = info.m.split(/[；;]/)[0].trim().slice(0, 12);
```

效果：多义词行内只显示第一个义项，其余义项仅在点击弹窗（`#pm` 全量释义）中可见。

## 变更后（R2 / 新规则）

```js
const parts = String(info.m).split(/[；;]/).map(s => s.trim()).filter(Boolean);
const two = parts.slice(0, 2).join('；');
const m = (two.length <= 12 ? two : parts[0]).slice(0, 12);
```

- 取前两个非空义项，以 `；` 连接；若连接后长度 ≤ 12 字则显示两义，否则退回只显示首义（仍截断 12 字）。
- 不产生尾部分隔符（`join` 只在两义之间加分隔符），不过滤掉空义项（`filter(Boolean)`）。
- 弹窗 `#pm` 仍显示全量释义，不受影响。

## 示例

- `swear`：`m = "咒骂；发誓"`（两义共 5 字 ≤ 12，行内显示两义）。
- 首义超长或两义合计超 12 字时，行内退回首义截断 12 字，与旧规则一致。

## E2E 加固

`inline-gloss` 新增 Step 5：扫描全部 `.gl` 行内释义，断言 ① 至少一个两义 gloss（twoSense > 0）；② 无尾部分隔符；③ 无空义项。
