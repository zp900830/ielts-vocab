## Global Constraints

- **允许改**：`app/**`、`playwright-tests/**`、`docs/**`。**不许进 diff**：根 `index.html`、`shadow/**`、`shadow/js/plan-engine.js`、`config.js`、`data/**`（只读）。
- **存储口径（§9.4 的「不新增存储字段」怎么落地）**：§9.4 的「不新增存储字段」指**不向共享的 `ielts.shadow.v2`（`ROOT2`）schema 加字段**（那是 `/app/` 与 `/shadow/` 同源共享的真值根，加字段会被影子跟读的 `recompute2` 抹掉）。收听账沿用 M1 已建的 3.0 私有 key `ielts.app3.article`（`LS_ARTICLE`，已在 `exportBackup` 的 `BACKUP_EXTRA` 里），**只扩一个 `listen` 段、不新建 key**。引擎 `ShadowPlan` 不加参数、不改导出。
- **§7.6 分开记账（M4 核心约束）**：收听**不碰精读**。任务模式的 `taskSentenceFinished` → `recordRep + bumpArticleRep`（精读次数）**保持不动**；随身听路径改走 `listenTick(gi)`（只记 `listen` 段：句数/时长/最近收听），**不再调 `onSentenceComplete`**（否则 contact 事件会写 `state.sents[].lastReadAt` → 抬高 §9.4 的 `everRead` → 抬高 §9.2 通读完成度 ×40%，精读熟练度就被口袋连播刷穿了）。因此「听了一段后精读句数/熟练度不变」。
- **§7.5 首页联动怎么既不违 §7.6 又真联动**：首页卡片「最近学习」= `max(本篇 state.sents.lastReadAt, 本篇收听 last)`（`articleStat.lastAt`）。听不改进度，但使「最近学习」真实反映你刚听过；「随身听默认播的那篇」= 同一派生取最大者。
- **不写第二套播放器**：卡片/展开的播放控制只调既有 `playFrom` / `togglePlay` / `step` / `setLoopCount` / `setRate` / `addMark` / `toggleAB`；不复制 `speak` / `launch`。
- **不新增浮层/页面**（§2.4 护栏）：`#/listen` 是 §2.2 的一级页，入口只有侧栏「随身听」；「展开全屏阅读」是同一屏的状态迁移（`body.listen-mode`，复用任务模式那套 `.layout`/`.audiobar`），**不是新页面、不是新浮层**。
- 视觉**继承**既有令牌（`--card` / `--border` / `--accent*` / `--grad` / `--note` / `--muted`），**不新造色**；深色全覆盖（`body.dark`）。
- 无障碍（§10.4）：卡片语义化（`h1` / 真 `button`）、位置条是 `<input type=range>`（可聚焦可键盘）、播放/切篇按钮有可读 `aria-label`、触摸目标 ≥44px、`prefers-reduced-motion` 沿用。
- 性能：卡片随播放状态更新只改文本/CDN 值（`updateListenCard` 就地更新，不整卡 `innerHTML` 重渲），别在 `paint()` 里重建 DOM。
- 分支纪律：已在 `agent/opencode-3.0-m4-0924`，**每任务一个 commit、不 push、不改历史**。
- 每任务收尾：`cd playwright-tests && npx playwright test journeys/app3/listen.spec.ts` 绿。收口任务再跑全量（基线 **247**）、`python3 scripts/validate_data.py`、`node scripts/build_site.mjs`。

```js
  /* ---- 3.0 随身听（M4，PRD §7）---- */
  // 该篇「最近学习」：精读 lastReadAt 与收听 last 取最大（§7.5，听不改进度只改「最近」）。
  function listenLast(a) {
    return (typeof TASK !== 'undefined' && TASK.listenLast) ? TASK.listenLast(a) : 0;
  }
  // 默认播哪篇：最近在学的那篇（= 首页「最近学习」最大的那篇）；全没动过 → 第 1 篇。
  function listenDefaultArticle() {
    let best = 0, bestAt = -1;
    for (let a = 0; a < SECTIONS.length; a++) {
      const at = Math.max(articleStat(a).lastAt || 0, listenLast(a));
      if (at > bestAt) { bestAt = at; best = a; }
    }
    return best;
  }
  function listenVolNo(a, idxLocal) {
    // 句 → 段 → 卷：复用单词本的 volNo（同一「卷」判据），idxLocal 是篇内本地下标
    const paras = SECTIONS[a].paragraphs;
    let n = 0, pi = 0;
    for (let p = 0; p < paras.length; p++) {
      if (idxLocal < n + paras[p].length) { pi = p; break; }
      n += paras[p].length;
    }
    return (typeof volNo === 'function') ? volNo(a, pi) : 1;
  }

      <h1>随身听</h1>

        <button class="ls-cover" type="button" aria-label="展开《${esc(SECTIONS[a].title)}》全文阅读">
          <span class="ls-art">《${esc(SECTIONS[a].title)}》</span>
```

```js
  function statsListen() {
```
