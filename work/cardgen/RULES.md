# 词卡补齐 · 子代理作业规则（所有代理共用，读完再动手）

你的任务**不是创作**，是**做选择题**。系统已经从三份资料、本书词表、课文原句里把候选抽好了，
你的职责只有一个：判断每条候选在**这个词头当前这个义项下**成不成立。

## 输入格式

你会拿到 `work/cardgen/need/<片号>.txt`，每行一个词头：

```
词头|释义|待办标记|syn[候选:来源,...]|col[候选:来源,...]
```

待办标记：

| 标记 | 含义 | 你要做的 |
|---|---|---|
| `syn` | 这张卡**完全没有**同义词段 | 从 syn[] 里挑出能替换的 |
| `syn+` | 已有同义词段，但**漏了大半组** | 只挑漏掉的成员，别重复卡上已有的 |
| `col` | 这张卡**没有**词伙段 | 从 col[] 里挑出真实、学生用得上的搭配 |

候选来源标签（**决定这条的可信度**）：

- `M` 两份同义替换资料成组（何琼等号改写 / 高频书中文释义相同）—— 最硬的书面依据
- `R` 反向索引：别的卡片已经把它列成同义词（上一轮逐条裁决留下的）
- `B` 顾家北《手把手教你雅思词伙》OCR 原文里出现的搭配 —— 按话题编排，正是本项目要的
- `T` 跟读篇课文原句里出现的搭配（窗口内其它词都是简单词）

## 判定标准（宁缺毋滥）

**保留**一条候选，必须同时满足：

1. 词头换成这个词，**在这张卡的释义下**句子仍然成立。释义是多义时，只要卡上写的那个义项对得上就行。
2. 词性一致（校验器会机械复查，但别浪费名额）。
3. 不是"同话题但不同义"。资料的小节是按话题编排的，`allergy` 和 `trauma` 都在疾病小节，但不是同义词 —— 这类一律否掉。
4. 语域/搭配范围大致相当。`happen` 和 `occur` 行；`happen` 和 `catastrophe` 不行。

**必须留空**的情况：候选看起来"有点像"但你说不清楚差在哪 —— 说不清就别写。宁可交空，不许猜。

## 关于自由作答（F）

- 默认**不提**任何候选之外的词。
- 只有当 `syn` 行、候选为空、且这是雅思里极常见的规范同义关系时，才允许提最多 1 个，
  并且它必须来自本书词表（3219 词）内的词。校验器会机械拒绝词表外的词。
- 词伙**一律不许自由作答**：没有 `B`/`T` 出处的搭配不落地。

## 输出（照抄，别改结构）

写到 `work/cardgen/got/<片号>.json`，与输入同片号：

```json
[{"w":"altitude","syn":["elevation"],"col":["high altitude","low altitude"]},
 {"w":"oxygen","syn":[],"col":[]}]
```

- 每行输入都要有一条输出，**包括全空的**（用 `[]`）—— 缺条会被当作未处理。
- 同义词最多 3 个、词伙最多 3 条，超出的丢掉。
- **每判满 25 行就整份覆盖写一次**，不要攒到最后一次写。上一轮有 4 个代理跑完没落盘，全丢了。
- 不要碰 `shadow/data/vocab.json`、`shadow/data/sections.json`、`shadow/index.html`，也不要 git 操作。
  落地由主流程统一做。

## 交回前自查

1. 输出条数 == 输入行数
2. 所有 `syn`/`col` 字符串逐字来自输入候选（自由作答除外，且不超过 1 个/词）
3. 小写、无标点、无中文、无 `[[...]]` 残留
