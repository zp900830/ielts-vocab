# 门禁 2 · 独立审核作业书（辨析卡草稿）

你不是草稿的作者。默认草稿是错的，直到你亲手在数据原文里把它验回来。
**只读数据 + 只写你自己的审核文件**；不许改草稿、不许碰 `shadow/data/*`、`shadow/index.html`、测试，
不许任何 git 写操作。

## 为什么还要人工审核（机检有哪些看不见）

`tools/check_compare_draft.py`（门禁 1）只扫 **code span（反引号里的英文串）**，而且为了不误报
故意跳过硬约束之外的三类行：含否定词的、像文件路径的、含 `:`/`=` 的键值式断言。
所以有四类错误它结构上抓不到，全靠你：

1. **表格里的中文与"引用原句"不是 code span** —— 草稿里「该段原文」表格是裸文本，
   抄错一个词、把两句话并成一句、译句错位，门禁 1 一个字都不会报。
2. **藏在否定行里的"正证据"** —— 作者可以把一条数据里根本没有的搭配写在"本书不写 X"这类句子里骗过脚本。
   要确认：凡是当作**正面证据**用的串（表格里、`eg`、出处清单里）必须真查得到；
   只有明确标成"不写/查不到/没有"的才允许查不到。
3. **数字口径** —— 宽度、全局句号、共现段数、出处条数，作者自己算的，可能算错也可能虚报。
4. **语义是不是编的** —— 把中文义项换个说法当"区别"、把"本书这两句恰好这么写"升级成语法禁令、
   同源文本被算成两条独立证据。

## 逐组必须做的 6 项（每项都要落一行结论，不许"看起来没问题"）

| # | 验什么 | 怎么算过 |
|---|---|---|
| A | **原文表逐字回数据** | 把草稿「该段原文」表格里每一行英文/中文，与 `shadow/data/sections.json` 对应 `章/段/句` 的原文（去掉 `[[词头:表面]]` 方括号标记后）**逐字比对**。标点、大小写、单复数、时态都算不符。不符 = **BLOCK**。 |
| B | **全局句号与共现段** | 章偏移 `[0,339,651,883,1277,1492]`；用 `章偏移 + 该段之前各段句数之和 + 段内序号` 自算，和草稿写的号对得上才算过。成员是否真的以 `[[词头:…]]` 出现在声称的共现段里。 |
| C | **正面证据全部可 grep** | 表格里、`eg`、`scene`、`core` 括号里、出处清单里每一条英文，自己去 `sections.json`（按**表面形式**）或 `vocab.json`（按 `ex`/`note` 原文）`grep -i` 找到。找不到的：若草稿明写"本书没有/不这样用" → 放行并记为"否定行"；若被当正面证据用 → **BLOCK**。 |
| D | **宽度复算** | CJK 字符计 1，其余（拉丁字母、空格、`=`、括号、标点）计 0.5。默认那一行 ≤40、总结句 ≤30。草稿标称的宽度和你算的不一样 = 记 MISMATCH（>1.0 算 BLOCK，作者要么算错要么虚报）。 |
| E | **不许复述中文义项** | 成员卡 `m` 里的中文词（「平坦的」「危及」「温和的」…）出现在 `core`、默认行、表头 = **BLOCK**；只出现在 `sense` 槽允许。 |
| F | **同源与厚度诚实** | 卡上词伙与课文某句是同一处文本时，草稿若在「证据强度」里把它算成两条独立出处 → MISMATCH；若据此宣称"两处书证方向一致" → BLOCK。另确认：**"证据薄"本身不是退回理由**（实测 98% 的组最薄一侧只有 1 处书证），不要拿这个当 BLOCK。 |

## 口味基线（他点头过的，用来判"这行写得好不好"，不改变 A–F 的硬结论）

- 每个成员一个钩子（场景 / 搭配 / 限定词括号），一行读完，不写"侧重…而…则…"式对仗废话。
- 「简单记：」那半句要能当天背下来。
- 共享义项名不副实时，**正确处置是**标题改写成"这一段两个词各领哪样东西"、义项只留在 `sense` 槽
  （见 `work/compare_slices/BRIEF.md` 第 6 条）。按这个标准看草稿有没有把"本段两词都指 X"写进标题 ——
  写进去而该段实际不撞 = BLOCK。

## 输出（必须落盘，边验边写，别攒）

写到 `work/辨析审核/<你分到的文件名>.md`：

```
# 门禁 2 审核 · <范围>
组数 N / BLOCK x / MISMATCH y / 通过 z

## 组 <worklist_idx> · a / b
A 原文表：OK / 不符：<哪一行、草稿写成什么、数据里是什么>
B 句号与共现：…
C 可 grep：…（列你亲自 grep 到的条数，和查无的条）
D 宽度：草稿 38.5 / 实测 41.0 → MISMATCH
E 义项照抄：…
F 同源诚实：…
判定：可落地 / 需作者改（列出必须改的最小清单）/ 建议退回（说明为什么不是改写能解决的）
```

报告只回：文件路径 + N/x/y/z + 需要我拍板的最多 3 条。不要把审核正文贴回对话。
