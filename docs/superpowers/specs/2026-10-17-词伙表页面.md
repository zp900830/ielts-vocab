# 2026-10-17 词伙表（新一级页面）

## 一、需求

> 「类似词库，再增加一个词伙列表，一个全新的列表。没覆盖到的都放最后，置灰。」

## 二、实现

| 项 | 值 |
|---|---|
| 路由 | `#/collocations` |
| 导航 | 左侧第 4 项「词伙表」（手机底栏第 4 格，6 格均分） |
| 数据 | `data/collocations.json`（3320 条，240KB） |
| 加载 | **懒加载**：只有进这一页才拉，不进首屏 `Promise.all` |
| 列表 | 已覆盖 1873 条在前、未覆盖 1447 条在后；未覆盖整行 `.42` 透明度 + 虚线边 |
| 交互 | 搜索（英文/中文/词头，输入即筛）；「跳到未覆盖」；「加载更多」100 条/批 |
| 行内容 | 英文搭配（粗） + 原书中文 + 右侧灰字词头（最多 2 个） |

数据结构：`[{"e":"air pollution","z":"空气污染","w":["pollution"],"c":1}, …]`
`c=1` 表示能挂到课文目标词（已覆盖）；`w` 是挂上的词头，用于搜索与展示。

## 三、为什么这么切

- 「覆盖」= 这条书里的搭配能被六篇课文的某个目标词接住（同一个词形还原规则）。
  挂不上的 1447 条不是坏数据，而是课文没学这些词（`leadership skills`、`computer literacy`…），
  所以排最后、压暗，不删。
- 不一次渲染 3320 行：沿用单词本的 `.wb-row` 骨架 + 100 条/批。
  但灰段在第 1874 行，用户不可能点 19 次「加载更多」——补一个「跳到未覆盖（1447 条）」。
- 页脚写明来源：「全部取自《顾家北手把手教你雅思词伙》3.0；置灰的是书里有、六篇课文没用到的搭配。」
