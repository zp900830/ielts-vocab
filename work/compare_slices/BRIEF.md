# 辨析卡草稿 · 作业说明书（所有切片共用）

任务：把指定切片里的辨析组，逐组写成「对比型辨析卡」的内容草稿。**只写草稿文件，不许改任何产品代码或数据文件。**

## 一、输入

- 切片包：`work/compare_slices/sliceNN.json` —— `worklist_idx` 是组在 `work/compare_groups_worklist.json` 里的下标；
  每组给 `words`（成员，**都是本书目标词**）、`senses`（共享义项）、`paras`（共现段落 `[章, 段]`）、`sents`（相关全局句号，0 基）。
- 数据源只有两份，**别的都不许当出处**：
  - `shadow/data/vocab.json` —— 词头卡：`m` 义项、`ex`/`exZh` 例句、`note`（字符串按「同义词：」「词伙：」两段读）
  - `shadow/data/sections.json` —— 6 章，`paragraphs[段][句]` 是带 `[[词头:表面形式]]` 标记的英文原句；另有 `sentZh`（同位译句）、`paraZh`（段主题）、`subheads`
- **禁止来源**：`work/confusable_groups.json`、PDF 同义替换表、何琼等号表、你自己的英语语感。PRD §5.10 定过：这些不喂辨析。

## 二、全局句号口径（别自己发明）

章累计偏移 `[0, 339, 651, 883, 1277, 1492]`，全书 1833 句。
`全局句 = 章偏移 + 该段之前所有段的句数 + 段内序号`。算完必须和切片包里的 `sents` 对得上；对不上就是算错了，回去重算，**不要改用别的编号**。

## 三、每组必须产出（照批次 1 的版式）

1. **共现位置** + **主锚点段**（多个共现段时取第一个，其余列出供表头改写）
2. **该段原文表**：全局句 | 英文原句（成员词加粗）| 中文译句
3. **表头一句（title）**：一句话交代"这一段在讲什么、为什么这两个词会同时出现"
4. **默认那一行（summary 的「简单记」）**：`A = 钩子（真实搭配），B = 钩子（真实搭配）`
   - **宽度 ≤40**：CJK 记 1、其余字符（字母/空格/括号/`=`）记 0.5，**必须标实测值**
   - 每个成员一个钩子（场景 / 搭配 / 限定词），**不许复述中文义项**，不许"侧重…而…则…"式对仗废话
5. **差异维度表（diff）**：2–4 个维度，每个维度两行（两个成员各一行），列 = 维度 | 词 | 常见搭配（**全部要有出处**）| 用在哪 | 一句话区别
6. **总结句**：≤30（同样标实测宽度）
7. **出处清单**：草稿里出现的**每一条英文串**一行一条 → `卡 \`词头\`.ex` / `卡 \`词头\`.note 词伙` / `课文 118`
8. **证据强度**：某成员卡上 `note` 没有词伙段、或全书只出现 1 次，**明说**，别硬凑

## 四、文体参照（他点头的口味，照这个写）

```
dawn = 出发的那个钟点（at dawn），sunrise = 早起看的那道景（golden sunrise）
deteriorate = 情况自己越来越糟，degrade = 物件被用得掉档（degrade fast）
endanger = 让活物遭殃（endangered species），jeopardise = 让事情黄掉（outing）
mild = 不冲鼻不刺激（mild detergent），moderate = 量不超标（a moderate dinner）
outskirts = 城边那一圈（on the dusty outskirts of town，工厂在）；suburb = 城外那片住宅区（a leafy suburb，孩子在等）
```
共同点：钩子是**画面或场景**，不是语法术语；括号里放的是课文/卡上真出现过的搭配。

## 五、硬约束（违反就是返工）

1. **不许造词、不许造搭配**。括号里、表里的每一条英文串，必须能在两份数据原文里查到。
   写完**必须自己跑门禁**，改到 0 条为止：
   ```bash
   python3 tools/check_compare_draft.py work/辨析草稿/<你的文件>.md
   ```
   查不到的只有两条路：换成数据里真有的搭配，或者那句改成中文描述并写明"卡上没有词伙段"。**不许**为了好看留一条查不到的。
2. **成员只能是切片给的 `words`**。不许把没卡、没在课文里被标出来的简单词拉进表里（`fog/haze/smoke` 这类）。
3. **整组同义（`all_synonyms: true`）照写**，区别落在词性 / 冠词与介词框架 / 搭配对象上。"越近越要写"是辨析，"越近越要删"是出题，别混。
4. 义项照抄检查：卡上 `m` 里的中文词（「平坦的」「危及」「温和的」）只能待在 `sense` 槽，`core` 和默认行一律换掉。
5. 中文用词：写"哪样东西 / 什么场景"，不写"该词用于…"这种词典腔。

### 五条口径（批次 1/2 代理反复来问，答案定死在这里，别再逐组上报）

6. **共享义项名不副实 → 不退回，照写但把话说轻**。worklist 的 `senses` 是两张卡 `m` 的交集，
   不是共现段里的实际用法（`gas/petrol` 那段 gas 译"气体"、`alien/foreigner` 那段 alien 是形容词）。
   处置固定为：**标题改写成"这一段两个词各领哪样东西"，worklist 那个义项只留在 `sense` 槽，
   不在标题或默认行里宣称"本段两词都指 X"**，并在「证据强度」补一句"本书没这样用过"。
   这就是批次 1A 组 2、组 5 他点头的同一处理，直接沿用。
   同族还有一种"**档位错**"：worklist 的义项取自两卡的**动词档**、共现段两处走的却是**名词档**
   （批次 4 的 murmur / whisper「低语」就是）。**同一口径处理，不必另立规则**，但必须写明"哪一档本书 0 处、
   哪一档的书证在别段"；**不许**把它升级成"本书没有这个词形"。
7. **证据薄不是退回理由**。实测 216/220 组（98%）最薄那一侧全书只有 1 处书证 —— 这是本书词表的
   常态，不是某一组的缺陷，拿它当门槛等于砍掉整张表。薄就如实写有几条出处，
   **不许**为了看起来厚去编语义层、也不许把"本书就这么写"升级成语法禁令。
8. **同一处文本不许算两条独立证据**。卡上的词伙常常就是课文那一句（`wide meadow` ↔ 课文 235、
   `brief despair` ↔ 课文 197）。数出处时同源合并，并在「证据强度」里点名哪几条同源。
9. **同一段末会挂多张卡，别为此改内容**。实测 51 段挂 ≥2 张、最多 5 张（章4 段20）。
   渲染成"段末一条辨析栏、默认一行一张、点开各出对比表"由我做；你只按 `worklist_idx` 升序排,
   同段的几张各写各的切入角、不重复即可。
10. **宽度只有一把尺，且上限不松**。`scripts/validate_data.py` 的 `_width`（2026-09-20 起）：
    **汉字与全角标点各记 1，其余（拉丁字母、空格、半角括号）记 0.5**；默认行 ≤40、总结句 ≤30。
    之前有三套标称（只数汉字 / 汉字＋中文标点 / 手算），落地以这把尺为准 ——
    你草稿里写的"实测宽度"如果与它不符，**改文本，不是改数字**。
    超宽最常见的成因是把两个英文例句都塞进括号里：宁可只留一侧的例句，或把中文钩子再缩两字，
    也不要把上限抬到 45。
    **"≤40" 对应的渲染是手机上两行以内，不是一行**（2026-09-20 实测 57 张卡 + 他当场拍板改的口径：
    段末容器 334px / 字号 13px，一行只装得下约 25 个汉字当量）。所以写的时候按"两行读完、不拖到第三行"来卡，
    不必为了凑单行把钩子砍掉 —— 但也别拿"反正两行"当理由往 40 上加字。
11. **表头可以引用义项当靶子，前提是你在否定它**。硬约束 4 说义项词只能待在 `sense` 槽；
    但口径 6 又要求标题"把话说轻"，实操上必然是
    「这一段两个词都不是在说"平坦"」这种句式 —— 引用义项 + 当场否掉，**放行**（批次 1A 组 2/组 5 已按此通过）。
    拦的是反例：标题**宣称**"本段两词都指 X"，而数据里那一处并不是 X。
14. **worklist 的 `all_synonyms` 和"两卡例句只差词头"打架时：按现表出卡，把同形写进「数据边界」当合法物证，不再逐组提请拍板。**
    `all_synonyms` 只是个机械位 —— 定义是"两张卡的『同义词：』栏有没有互列"（`tools/confusable_groups.py:301`），
    它**结构上不可能**反映例句的形状，所以标 false 既不代表不同义、也不构成退回理由（批次 4 的 114 jail/prison、131 happen/occur 就是这个形状）。
    写法三件齐：① 同形这一事实照写（这是本书最强的"可换"物证）；② 同时补一句"两栏没互列，故 false 有据"；
    ③ 同形那两句**各算一侧书证**，不许并成一条、也不许据此否认同形。
15. **任何"本书没有／0 引用／某词各有自己的卡"式存在性断言，和"这串是书证"同等对待：自己 grep 过再写。**
    反例可以查不到（那正是你要声明的内容），但**关于"有／没有"的那句话本身必须查得到**。
    批次 4 的反面教材：草稿写「affect / impact / **influence** 三词各有自己的卡」，而 `influence` 根本没有卡
    （它只是三张卡同义词栏里的一个词条）—— 下游修卡的人照这句话去 `vocab.json` 找就撞空。
    四批下来**"虚报本书没有"是 MISMATCH 的最大单一来源**（`pepper grains`／`sacks`／`sitting room`／`box office`／
    `seat belt`／`compulsory`／`manager`／`opportunity`／`struck` 全属这一族），交稿前把否定行里的断言逐条回数据自查一遍。
12. **段主题栏 `paraZh` 不是出处，也不许当"这一段在讲什么"写**。批次 3 实测（2026-09-21 复核）：
    章3 的 66 段里，**段 22–43 的主题栏 = 段 0–21 的主题栏原样重抄一遍再挂尾缀「 灯下团聚，欢语不断。」**
    （`paraZh[i+22] == paraZh[i] + 尾缀`，i=0…21 全中；其余 5 章零重复）。所以那 22 段里主题栏写的
    「买了热汤」「孩子们挥手」「已是黄昏」全属别的段落 —— 3_08 就是照抄它写表头，被判 3 处 MISMATCH。
    判据："这一段在讲什么"**只能由 `paragraphs` 里真有的句子撑**；要提主题栏必须逐字引并标明"（段主题栏，本段句子不含此事）"。
    **章3 段 22–43 一律按主题栏不可用处理**，其余段落可当背景但只写句子撑得住的部分。
13. **任何"某词全书出现 N 次"必须写清是哪种口径，且默认两种分开列**：
    「带 `[[词头:…]]` 标记的 N 处 ＋ 没打标记的 M 处」。批次 1/2/3 三次栽在同一处 ——
    只报标记数会让"非人主语是 simulate 独有""mimic 全书只这一次"这类结论不成立
    （课文 227 就有一处未打标记的 `mimics a wet rainforest`）。宁可写"标记 2 处、另有 1 处未标"，
    不许把两档并成一个数。

16. **「该段原文表」里只粗本组的两个成员词**（§三 第 2 条的原话）。别的词一律不粗 ——
    包括那些确实挂了 `[[词头:…]]` 但不在本组的词（批次 5 的 1719 `surprising` 就是这一类），
    更包括**既没卡也没标记**的词（1716/1718 的 `grew`，审核按建议级没拦）。
    理由：读的人只会记住"加粗＝这组词在比"，粗多了等于没粗；反过来把成员词漏粗会让机检以为槽位空着。
    落地器只读 items 表，这张表纯粹给人复查出处用 —— 但一旦口径漂移，下一批代理就会来回改（批次 5 就改了三轮）。

## 六、交付与断点（重要）

- **小标题必须写成机检认得的形状**（批次 2 有 3 个切片因为写法五花八门被返工补格式）：
  - 组标题：`## 组N · wordA / wordB —— 共享义项`（`组` + 数字开头，别的编号形式如 `## 3.` 会被**静默跳过**，"全绿"里就没量到它）
  - 默认行：`### 默认那一行（实测宽度 38.5 / ≤40）` 紧跟一个 **``` 代码围栏**，围栏里只放那一行本体
  - 总结句：`### 总结句（实测宽度 23.0 / ≤30）` 紧跟一行（可以 `>` 引用），别加别的字
  - 每组另起一行 `主锚点 = 章N 段M`（落地填挂段位置就用这个字段名，不要只写「共现位置」）
- **宽度别手算**，用那把尺量：
  ```bash
  python3 -c "import sys;sys.path.insert(0,'tools');from width_rule import width;print(width('把默认行粘这里'))"
  ```
- **不许跑的脚本**：`tools/land_compare.py`（连 `--dry-run`/`--check` 都会覆盖 `work/辨析审核/land_preview.json`，
  批次 3 有个代理这么干过、只能靠 `git checkout` 擦回去）。草稿自检只用 `check_compare_draft.py` 与 `width_rule.py`。
- 输出到 `work/辨析草稿/<批次>_<切片号>.md`，**每写完 1 组立刻落盘**（不要攒到最后一次写）。
  上一轮有过整会话崩掉、7 个代理 4 个的产出全没的教训 —— 落盘优先于优雅。
- 文件开头写 3 行小结：几组、门禁结果、哪几组你要提请人拍板（证据太薄 / 共享义项名不副实）。
- 报告只回：文件路径 + 组数 + 门禁 PASSED/FAILED + 待拍板项。**不要**把草稿正文贴回对话。
