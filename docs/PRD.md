## 1. 产品定位与背景

### 1.1 一句话定位

把 3245 个雅思核心词编进 22 章主题故事 + 6 大影子跟读篇章（1833 句），用「情境阅读 + 逐句跟读 + 间隔复习 + 随身听连播」四位一体的方式，让雅思考生在真实语境里记住单词、听懂句子、说对发音。

> 词数口径统一（2026-09-23 实测）：`data/vocab.json` 与 `shadow/data/vocab.json` **都是 3245 条**，且这 3245 就是跟读课文里 `[[词:形式]]` 标记去重后的**目标词全集**（`ALL_TARGET_WORDS`）。界面「已毕业 N / 3245」用的就是它。旧文档里的 3219 是加词前的快照，别再引用。

### 1.2 解决的核心问题

| 痛点 | 现状 | 本产品解法 |
|------|------|-----------|
| 词义孤立 | 单词卡正反面脱离语境，记了就忘 | 22 章主题故事，每词只在首次出现时标注，一词一句、跨句去重 |
| 听说割裂 | 背单词 App 不管发音，跟读 App 不管词义 | 情境阅读 + 影子跟读两个应用**共用同一份 3245 词库**（数据同源；界面上**没有**互跳入口，见 §5.4） |
| 难坚持 | 缺乏进度感、无云同步、换设备归零 | 学习统计 + 艾宾浩斯间隔复习 + Supabase 云同步 + PWA 离线 + 随身听锁屏连播 |

### 1.3 价值主张

| 维度 | 承诺 |
|------|------|
| 内容规模 | 3245 词 × 22 章 × 135 故事 × 6 跟读篇章 × 1833 句 × 308 段人工校对译文 |
| 体验 | 单文件 PWA、秒开、无广告、无信息流；薄荷绿 + 衬线故事体 + 毛玻璃播放条 |
| 学习闭环 | 读→查→测→复→听→说，六步完整覆盖 |
| 数据主权 | 访客数据本地存储；注册后云同步；支持 CSV/TXT/Anki/JSON 全量导出 |

### 1.4 商业模式

当前版本完全免费、无广告、无内购。运营成本由维护者承担（Supabase Free Tier + 腾讯云 EdgeOne Pages（GitHub Pages 备用）静态托管 + Azure Speech F0 免费层每月 50 万字符）。

## 2. 用户画像

### 2.1 核心用户

- **身份**：备考雅思的中国大陆考生
- **目标分数**：6.0–7.5
- **词汇量**：3000–6000
- **设备**：移动端为主（iOS Safari / Android Chrome / 微信内置浏览器），桌面端为辅

### 2.2 次要用户

- 托福 / PTE / CET-6 考生
- 成人英语自学者
- 英语教师（用作课堂素材）

### 2.3 典型使用场景

| 场景 | 描述 | 对应功能 |
|------|------|---------|
| 通勤听读 | 地铁/公交上锁屏连播故事，到站自动断点续听 | 随身听 + Media Session + 云端 TTS |
| 精读精练 | 午休时打开故事逐句阅读，点词查义，完成篇末测验 | 情境阅读 + 单词弹窗 + 测验 |
| 口语跟读 | 睡前用影子跟读逐句模仿，A-B 循环攻克长难句 | 影子跟读 + 单句循环 + A-B 复读 |
| 碎片复习 | 课间 5 分钟刷一轮到期的间隔复习卡片 | 生词本 + 艾宾浩斯复习 |
| 换设备续学 | 从手机切到平板，登录同一账号无缝继续 | Supabase 云同步 |

## 4. 功能规格 · 情境阅读主应用

> 文件：`index.html`（4636 行，单文件 PWA）

### 4.1 导航与视图

应用采用四视图单页架构，桌面端左侧固定玻璃侧栏导航，移动端底部 Tab Bar：

| 视图 | 入口 | 功能 |
|------|------|------|
| 首页（home） | 侧栏「首页」 | 章节筛选 + 故事列表 + 阅读入口 |
| 阅读页（reader） | 点击故事卡片 | 沉浸式阅读 + 单词弹窗 + 朗读条 + 测验 + 目标词速查 |
| 学习统计（stats） | 侧栏「学习统计」 | 掌握度总览 + 词汇列表 + 筛选排序 + 详情弹窗 |
| 生词本（fav） | 侧栏「生词本」 | 收藏词列表 + 间隔复习 + 导出 |
| 我的（me） | 侧栏「我的」 | 账号管理 + 学习分析 + 数据备份 + 使用指南 |

### 4.2 首页 · 故事列表

**功能描述**：

- 章节筛选下拉：全部章节 / 单章（显示各章目标词数）
- 故事卡片列表：序号 + 英文标题 + 中文标题 + 元信息（目标词出现数、测验题数、最好成绩、已听/未读状态）
- 游客限制：仅可阅读第 1 篇故事，其余显示「登录解锁」
- 待审批提示：已注册但未通过审批的用户看到等待提示横幅

**数据源**：`stories.json`（135 篇），按 `ch` 字段分属 22 章。

### 4.3 阅读器

**核心交互**：

| 功能 | 说明 |
|------|------|
| 目标词高亮 | `{{word}}` 标记的词渲染为绿色下划线 `.tw`，点击打开单词弹窗 |
| 非目标词可查 | 所有英文单词均可点击（`.ow`），自动词形还原后查词典 |
| 逐句译文 | 桌面端：鼠标悬停句子左侧出现「译」按钮，点击展开/收起该句中文译文 |
| 点句译文模式 | 移动端：开关按钮控制句尾「译」圆钮显隐，触摸设备首次进入自动开启 |
| 显示全部译文 | 一键展开/收起所有句子译文 |
| 点句朗读 | 点击句子本身朗读该句（读完自动停），点播放键可继续连读 |
| 上下篇导航 | 阅读头部显示「上一篇/下一篇」按钮，按当前章节筛选范围切换 |
| 阅读位置记忆 | 600ms 节流记录滚动位置，下次打开自动恢复（含图片/字体加载后三次校正） |
| 沉浸模式 | 滚动 >40px 后阅读头部收缩（`.shrunk`），侧栏隐藏 |

**单词弹窗（wpop）**：

- 内容：单词 + 英/美双音标（带发音按钮）+ 释义（多义项按语境排序）+ 例句 + 例句中文
- 语境消歧：非目标词根据所在句译文自动排序义项，命中义项内关键词高亮
- 掌握度显示：已测验的词显示当前等级（陌生/眼熟/基本掌握/牢固）+ 分数
- 收藏按钮：☆ 加入收藏生词本（自动进入间隔复习计划）
- 出现篇目：显示该词出现在哪些故事中，可点击跳转定位
- 智能定位：桌面端在词右下方弹出（超边界翻转），移动端固定底部抽屉
- 焦点管理：`role=dialog` + Tab 焦点陷阱 + 关闭后归还焦点

**朗读条（audiobar）**：

- 播放/暂停 + 停止 + 上一句/下一句
- 进度条（range slider）：显示当前句/总句数 + 预估时间
- 语速选择：0.6x / 0.75x / 0.85x / 1x / 1.15x / 1.3x
- 音色选择：☁ Azure 云端（8 种）/ ⚡ Edge 免费自然语音 / 🖥 本机语音
- 逐句高亮跟随：当前朗读句加 `.speaking` 背景高亮

**目标词速查面板（wq-panel）**：

- 右侧竖排「目标词速查」标签，点击展开/收起
- 列出本篇所有目标词：单词 + 英美音标 + 释义 + 例句
- 搜索过滤（150ms 防抖）
- 键盘导航：↑↓ 切换卡片、Enter 朗读选中、Esc 收起
- 定位按钮：点击跳转到正文中该词位置并高亮闪烁
- 滚动/朗读时自动隐藏标签，停止后浮现

**篇末测验（quiz）**：

- 每篇故事配 5–10 道选择题（题干+选项全英文，避免靠中文蒙答案）
- 选项随机打乱顺序
- 提交后显示：得分/总题数 + 百分比 + 逐题对错标记 + 中文详细解析
- 结果自动计入学习统计（答对/答错更新掌握度）
- 操作按钮：重做本篇 / 下一篇故事 / 查看学习统计
- 最好成绩记录：`S.quiz[storyId] = {attempts, best, lastTs}`

### 4.4 学习统计

**总览指标**：

- 整体掌握度（百分比）
- 目标词汇总数
- 四级分布：牢固 / 基本掌握 / 眼熟 / 陌生（+ 未测）
- 测验总次数

**掌握度算法**：

```
score = min(100, 正确次数×12 + 点查次数×3 - 错误次数×8)
等级：score≥85 牢固 | ≥65 基本掌握 | ≥40 眼熟 | <40 陌生
```

**词汇列表**：

- 筛选：按等级（四级 + 全部 + 未测）
- 搜索：按单词模糊匹配（200ms 防抖）
- 排序：掌握度最弱优先 / 最好优先 / 答错最多 / 点查最多 / 字母顺序
- 每行显示：单词 + 音标 + 进度条 + 等级标签 + 正确率 + 点查次数 + 出现篇数
- 分页加载：每次渲染 120 条，「显示更多」按钮追加
- 点击行：弹出详情弹窗（含跳转复习链接）

**近 7 天学习趋势**：柱状图显示每日学习词数。

**学习建议**：根据薄弱词数量、正确率等自动生成高/中/低优先级建议。

### 4.5 生词本与间隔复习

**生词本**：

- 来源：阅读时点击非目标词 → 弹窗中 ☆ 收藏
- 列表：按收藏时间倒序，显示单词 + 音标 + 释义 + 来源故事
- 操作：移除 / 点击来源跳转到故事定位该词
- 到期提示：显示「N 个已到期」或「下次复习时间」

**艾宾浩斯间隔复习**：

- 复习间隔：5分钟 → 30分钟 → 12小时 → 1天 → 3天 → 7天 → 15天 → 30天
- 卡片式交互：先显示单词 → 点击「显示答案」→ 揭示释义+音标+例句 → 选择「认识/不认识」
- 认识：进入下一间隔阶段
- 不认识：重置为 5 分钟后再次到期，本轮末尾重新出现
- 进度显示：N/总数 · 认识 X · 不认识 Y
- 键盘快捷键：Space 揭示 / → 认识 / ← 不认识
- 完成页：统计本轮结果 + 提示不认识的词 5 分钟后再来

**导出**：

- CSV 格式（word, phonetic, definition, source）
- TXT 纯文本（word - definition）
- Anki 制表符分隔（word\tdefinition）

### 4.6 随身听（文章连播）

独立于阅读页朗读条的全局连播系统，右下角入口：

**入口形态**：

- 未播放：右下角固定圆形玻璃按钮（耳机图标），hover 显示断点信息
- 播放中：旋转封面悬浮球（章节号 + 标题首字母/封面图），附暂停/停止按钮
- 点击悬浮球：打开全屏播放器浮窗

**播放器浮窗**：

- 当前文章信息：标题 + 中文副标 + 章节 + 句进度
- 正文展示：当前句高亮 + 上下文可见 + 译文（可配置）
- 播放条：播放/暂停 + 停止 + 上一句/下一句 + 进度条 + 语速 + 音色
- 设置面板（可折叠）：

| 设置项 | 选项 |
|--------|------|
| 范围 | 全部文章 / 未读 / 已读 |
| 顺序 | 顺序连播 / 随机 |
| 模式 | 纯英文 / 英中对照 |
| 循环 | 列表循环 / 单篇循环 / 播完即停 |
| 句间停顿 | 0 / 0.5s / 1s / 2s |
| 报篇名 | 开 / 关 |
| 定时 | 不定时 / 播完本篇 / 15/30/45/60 分钟 |

**播放状态机**：`title → (en → tr?)* → 篇尾 → 下一篇/循环/停止`

**锁屏/后台续播**：

- Media Session API：标题=当前句前 80 字，artist=IELTS Vocab，系统控件可 play/pause/prev/next
- Screen Wake Lock：防熄屏中断
- 回前台自动检测并续播
- iOS 保活：每 5s pause()+resume() 踢一脚
- 云端音频 1s interval 监控暂停并自动 resume

| 项 | 口径 |
|---|---|
| 五态 | `fresh 陌生 → seen 已见面 → recognized 文中可辨 → owned 义项直连 → graduated 已毕业` |
| 接触是货币 | 完整跟读一句 = 句内**每个**目标词各 +1 接触；读句子本身就是背单词。**2026-09-22 保温第一期起这条对毕业词同样成立**：到期的毕业词会重新被排进句子，读到它照样进账（`reps` 续加、`due` 顺延 14 天），只是 `stage` 不回退。旧口径「毕业词不计」是"毕业 = 永不再见"这半个 bug 的正身 —— 引擎把它排回队列却不记账，同一句会被天天重排、保温配额全浪费在它身上（`plan-engine.js` `replay` 的记账处 + `shadow/index.html` 的 `readDone`） |
| 接触去重 | 键 = `词 + 句 + 日`，同一天反复回放同一句只算一次（毕业不能被一句刷出来） |

| 两个语境 | 课文句 + 卡上例句 `ex` 各答对一次才算 `recognized`；例句题在 ② 末尾补 |
| 重点词 | 连错 3 次标 `leech`，只加密度、**永不隐藏** |
| 间隔表 | `WORD_INTERVALS`（20 档）+ 毕业后 `[14, 30]` 天；`reps ≥ 12` 且 `ok3 ≥ 1` 才毕业（门槛 20→12 于 2026-09-22 落地，理由见下面「保温」行；`[1]=30` 那档仍然取不到，是死值） |
| **保温**（2026-09-22 第一期） | 毕业后**不是**永不再见：每 14 天到期一次，回到 A 池继续被排进句子。但**每天为它新排的句数有硬上限** `BAOWEN_CAP_SENTS = 8`（单位是**句**，与预算同单位；某句已因未毕业词被排进来时，句里的毕业词免费顺带、不吃配额）。上限是**防塌**不是优化：3245 词按 14 天回访，稳态约 232 词/天到期，不设上限 = 新词当天被挤光，实测连每天 60 分钟都三年内到不了终点。每天不到 15 分钟**不保温**（`BAOWEN_MIN_MINUTES`），界面那行如实说出来。判据与数在 `work/保温预算-实测-2026-09-22.md` §8–§9 |

**排程与预算**

| 项 | 口径 |
|---|---|
| 唯一输入 | 每天有多少分钟（**1–180，默认 15**；`initPlan` 的钳位就是这三个数）。**没有**总天数、没有慢/正常/快三档。低于 15 分钟仍可排今天这批，只是**不保温**（§5.9 保温行） |
| 三池 | A 到期复习（含到期的毕业词 = 保温）→ C 新词 → B 深化；预算花完就停。毕业词**只进 A**，不许进 B —— B 池的取句在保温配额循环之外，进 B 等于绕开上限 |
| 预留成本 | **只算通读时间**（2026-09-22 D10）：一句代价 = `secNew` 25s / `secReview` 8s，可被 `rate` 缩放；② 挖空选择照出照答但**不占分钟数**，例句题同理 ⇒ `usedSec ≤ 预算` 由构造保证。别把做题时间加回去（他原话与理由见 `plan-engine.js` 里 `budget` 那段注释） |
| 不生成欠账 | 断更 N 天回来，今天的量还是分钟数说了算；没读的词永远留在池子里 |
| 地板 | 空队列时保底给 1 句 + 1 题，保连续天数，但不装作今天很充实。**保底只从未毕业词里挑**：毕业词是被配额拦下来的、不是"预算装不下"，拿保底绕过配额等于把"低档不保温"偷偷改成"每天还是排一句" |
| 日界 | 默认凌晨 4 点算换一天（可设 0/2/3/4/5/6）；`dayKey(ts, boundaryHour)` |

| 步 | 做什么 | 遮什么 | 记账 |
|---|---|---|---|
| ① 通读 | 这批句子按原播放链完整跟读，倍速/A-B/逐句重听照旧 | 不遮 | 每个未毕业词 +1 接触 |
| ② 挖空选择 | 每句遮 1 个目标词，四个**英文**候选（1 真 3 干扰）+ 译文里把这个位置的意思划出来；末尾例句题同口径 | 遮**英文目标词**（保留词长） | 答对 → 该语境 +1 **且**记 `ok3`（`→owned`，`reps≥12` 即毕业）；答错 → 弹辨析表 + `due` 拉回今天 |

- 批次在 ① 开始那一刻**快照**：队列是滚动的，不快照就会发现 ② 无题可出。
- 每遍之间弹**遍间小结**（三个数字，且只在这里出现一次）。
- **底部只有一条浮空玻璃卡（任务条），它同时是唯一的进度面与唯一的拖动条**（数字唯一性见本节下面的表；玻璃卡样式见 §11.4）。卡内**一行按钮**：
  左侧文字两行 —— 主行「① 通读 n/N」+ **可拖动的定位条**（`#tbSeek`，真拖动、吸附到句），辅行左「还剩 ~N 分钟」/右「本次已用 M 分钟」（开跑前 20 秒不给第二个数）；
  右侧一排，**从右往左：放这一句 → 再来一遍 → 上一句 → 播放组（书签 / 循环次数 / A-B / 倍速四类弹层全收进这组）**；最右上角一颗纯图标退出，
  点了**不立刻退**，先换成「继续做 / 退出」两颗让他确认。倍速在任务模式里必须可见可点（`#rateCycle`）。
  ② 做题态整条播放控件**消失**，卡内只剩「回看句子 / 跳过这题」+ 退出，**不放推进按钮**。
  依据：2026-09-22 底栏定稿（"底部一条通栏、**一行按钮**"是他当日**第二次**改口，按最后一句重做）+ 2026-09-23 一步一停。
  旧口径「① 态留一条极窄播放行、播放·暂停也挂在条上」**已废**；原型 `docs/prototype/2026-09-20-任务模式原型.html` 只作历史参考（`:382` ③ 选义那一步 09-22 已删）。
- **当前句只有一套高亮**（`.sent.playing` 恒 1 句、`.sent.task-new` 恒 0），读完一句立刻从"今天这批"的标记里退出去。
  踩过的两个坑：CSS 里 `.sent.task-new` 写在 `.sent.playing` 之后 → 整页看起来"全都高亮"；`.playing` 的 `background` 被后面那条盖掉 → 换不过去。
- **刷新时那一行是"续读条"，不是弹窗**（弹窗每刷一次都要点掉一次，就是新的打断源 —— 他 2026-09-20 明确否掉）。判据只剩两条、都在"今天的活"这一本账上：
  **今天计划句数 > 今天已读句数** 且 **今天没按过「今天先不做」**（后者按天记在 `ielts.shadow.resumeDay`，隔天照常提）。
  2026-09-23 他把"提几次"拍死：「每次都提（只要今天没完成）」。原先还有一把 sessionStorage 锁记"这趟浏览器会话提过没有"（`:start` / `:resume` 两格），**已删**：
  它省下的不是屏幕是一致性，而"同一个动作有时有反应有时没反应"被他当场当成 bug 报了上来（实测两个条并没有重叠，多出来那条就是这张卡）。
  今天一句没读 → 写「今天 N 句」+ 绿按钮「开始」，辅行留空不给第二个数；读了几句 → 写「还没做完 · 已读 N/M · 还剩 X 句」。
  它**不许把播放条挤掉**；与断更 toast（`gap > 2`）同屏只冒一条；顶栏「今日」绿点与它读同一份 `todayLeftN()`。
- 做题卡卡头**不复述** `n/N`：今日进度唯一的家是任务栏（§10.1 数字唯一性表），回看句子也全页只有一颗。
- **推进按钮全页只有一颗**，在任务条上（它同时是键盘 `→` 的等价物）；做题卡里不摆第二颗。
  末题那一下写「小结」不写「下一题」—— 点下去是真的收遍。依据：`docs/superpowers/specs/2026-09-22-任务模式走查.md`「这批的落点」#1。
- **② 答错的词在本遍末尾补考一次，每词只一次，中途不打断**（他 2026-09-22 拍板「当场闭环一次」；
  否掉的两个方案与理由在同一份文档「这批的落点」#2）。补考挂在**同一份** `quizList()` 末尾，不另开流程：
  分子分母同一份账、事件只有一本、「错 N」不双记；补考再错也不再补（否则收工没有尽头）。
  这本账只在**遍间小结**那一行说一次，任务条不加第四个数，措辞不许写成"欠 / 待补 / 积压"。

## 9. 语音合成系统

### 9.1 三级音色架构

| 级别 | 来源 | 音质 | 要求 |
|------|------|------|------|

| ⚡ Edge 免费 | Edge 浏览器内置 Online Natural 语音 | ★★★ | 用 Edge 打开 |
| 🖥 本机 | 浏览器 speechSynthesis API | ★~★★ | 无 |

### 9.2 Azure 云端音色清单

| 口音 | 音色 | 性别 |
|------|------|------|
| 英式 en-GB | SoniaNeural | 女 |
| 英式 en-GB | LibbyNeural | 女 |
| 英式 en-GB | RyanNeural | 男 |
| 英式 en-GB | ThomasNeural | 男 |
| 美式 en-US | AriaNeural | 女 |
| 美式 en-US | JennyNeural | 女 |
| 美式 en-US | GuyNeural | 男 |
| 美式 en-US | AndrewNeural | 男 |

默认音色：`en-GB-SoniaNeural`

### 9.3 合成管线

```
用户触发 → 串行请求队列（150ms 间隔）→ 三级缓存查找
  ├─ 命中内存 Map（≤120 条 blob URL，LRU 淘汰）→ 直接播放
  ├─ 命中 IndexedDB（iel-audio/clips，持久跨会话）→ 加载到内存 → 播放
  └─ 未命中 → POST /functions/v1/tts {text, voice, rate}
       ├─ 成功 → blob URL → 写入两级缓存 → 播放
       └─ 失败 → 600ms 后重试一次 → 仍失败 → 降级本机语音
```

缓存 key：`r2|voiceId|rate|text`

### 9.4 预取策略

- 主站随身听：当前句 + 下一句预取
- 跟读应用：8 句预取（≈40-80s 缓冲），锁屏后台被节流时仍无缝续播
- 循环/AB 模式：只发单句链（预取会打乱循环计数）

### 9.5 错误处理与降级

| 错误码 | 含义 | 用户提示 |
|--------|------|---------|
| 403 forbidden | 需账号审批 | "请先等待管理员审批" |
| 401 | 未登录/token过期 | "请先登录" |
| 503 | 未配置 | "云端语音暂未开放" |
| 403 | Azure 密钥无效 | "Azure 密钥无效或区域不匹配" |
| 429 | 配额用尽 | "请求频繁或配额用尽" |

降级链：云端失败 → 本机语音继续 + toast 提示（30s 内不重复）

## 12. 测试与质量保障

### 12.1 E2E 测试（Playwright）

**规模（2026-09-23 实测）**：`playwright-tests/` 下 **36 个 `.spec.ts`**（跟读 34 + 主站冒烟 + admin 队列），全量 **151 条用例**，跑完约 2.2–2.5 分钟。

**规格源是 `tests/e2e/shadow/*.md`（30 份），不是 spec**：每份 md 手工复述一条用例，spec 头部标着 "Source is authoritative — do not edit; re-compile from markdown if broken"。**改了 spec 必须同步改 md**，否则下次重编译会把修复冲掉。因此本文件不再维护「哪个文件测什么」的清单（它每轮都过期）—— 要看覆盖，`ls tests/e2e/shadow/` 读标题即得。

**引擎层另有单测**：`plan-engine.spec.ts` 直接在 Node 里跑 `ShadowPlan`（接触 / 毕业 / 保温配额 / `estimateDays` / 补考 salt 只换排法），不需要浏览器。

**几条被咬过之后定下的硬规矩**（全表见 `tests/e2e/shadow/conventions.md`）：
- **必须 `cd playwright-tests` 再跑**。在仓库根跑会假报 `did not expect test.describe() to be called here`，症状和「spec 语法坏了」几乎一样。
- **凡以句子下标为坐标的用例（书签 / 续读位 / A-B），进页面后必须先等正文渲够**：`expect.poll(() => page.locator('.sent').count()).toBeGreaterThan(最大下标)`。正文是异步渲的，没等到就会被 `x.i < sents.length` 静默过滤 —— 这是 2026-09-23 那条「隔几次红一次」的真根因，且**干净 profile 单跑会掩盖它**。
- 断言里的数字一律现取，不写死（句数、词数、卡面文案都是）。

### 13.4 缓存与发布面（EdgeOne，不是 netlify.toml）

- 静态资源（CDN 图标 / 字体）：长期缓存。
