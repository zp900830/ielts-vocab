## 1. 产品定位与背景

### 1.1 一句话定位

把 3219 个雅思核心词编进 22 章主题故事 + 6 大影子跟读篇章，用「情境阅读 + 逐句跟读 + 间隔复习 + 随身听连播」四位一体的方式，让雅思考生在真实语境里记住单词、听懂句子、说对发音。

### 1.2 解决的核心问题

| 痛点 | 现状 | 本产品解法 |
|------|------|-----------|
| 词义孤立 | 单词卡正反面脱离语境，记了就忘 | 22 章主题故事，每词只在首次出现时标注，一词一句、跨句去重 |
| 听说割裂 | 背单词 App 不管发音，跟读 App 不管词义 | 情境阅读 + 影子跟读双应用打通同一份 3219 词库 |
| 难坚持 | 缺乏进度感、无云同步、换设备归零 | 学习统计 + 艾宾浩斯间隔复习 + Supabase 云同步 + PWA 离线 + 随身听锁屏连播 |

### 1.3 价值主张

| 维度 | 承诺 |
|------|------|
| 内容规模 | 3219 词 × 22 章 × 135 故事 × 6 跟读篇章 × 1809 句 × 308 段人工校对译文 |
| 体验 | 单文件 PWA、秒开、无广告、无信息流；薄荷绿 + 衬线故事体 + 毛玻璃播放条 |
| 学习闭环 | 读→查→测→复→听→说，六步完整覆盖 |
| 数据主权 | 访客数据本地存储；注册后云同步；支持 CSV/TXT/Anki/JSON 全量导出 |

### 1.4 商业模式

当前版本完全免费、无广告、无内购。运营成本由维护者承担（Supabase Free Tier + Netlify/GitHub Pages 静态托管 + Azure Speech F0 免费层每月 50 万字符）。

## 2. 用户画像

### 2.1 核心用户

- **身份**：备考雅思的中国大陆考生
- **目标分数**：6.0–7.5
- **词汇量**：3000–6000
- **设备**：移动端为主（iOS Safari / Android Chrome / 微信内置浏览器），桌面端为辅

### 2.2 次要用户

- 托福 / PTE / CET-6 考生
- 成人英语自学者
- 英语教师（用作课堂素材）

### 2.3 典型使用场景

| 场景 | 描述 | 对应功能 |
|------|------|---------|
| 通勤听读 | 地铁/公交上锁屏连播故事，到站自动断点续听 | 随身听 + Media Session + 云端 TTS |
| 精读精练 | 午休时打开故事逐句阅读，点词查义，完成篇末测验 | 情境阅读 + 单词弹窗 + 测验 |
| 口语跟读 | 睡前用影子跟读逐句模仿，A-B 循环攻克长难句 | 影子跟读 + 单句循环 + A-B 复读 |
| 碎片复习 | 课间 5 分钟刷一轮到期的间隔复习卡片 | 生词本 + 艾宾浩斯复习 |
| 换设备续学 | 从手机切到平板，登录同一账号无缝继续 | Supabase 云同步 |

## 4. 功能规格 · 情境阅读主应用

> 文件：`index.html`（4597 行，单文件 PWA）

### 4.1 导航与视图

应用采用四视图单页架构，桌面端左侧固定玻璃侧栏导航，移动端底部 Tab Bar：

| 视图 | 入口 | 功能 |
|------|------|------|
| 首页（home） | 侧栏「首页」 | 章节筛选 + 故事列表 + 阅读入口 |
| 阅读页（reader） | 点击故事卡片 | 沉浸式阅读 + 单词弹窗 + 朗读条 + 测验 + 目标词速查 |
| 学习统计（stats） | 侧栏「学习统计」 | 掌握度总览 + 词汇列表 + 筛选排序 + 详情弹窗 |
| 生词本（fav） | 侧栏「生词本」 | 收藏词列表 + 间隔复习 + 导出 |
| 我的（me） | 侧栏「我的」 | 账号管理 + 学习分析 + 数据备份 + 使用指南 |

### 4.2 首页 · 故事列表

**功能描述**：

- 章节筛选下拉：全部章节 / 单章（显示各章目标词数）
- 故事卡片列表：序号 + 英文标题 + 中文标题 + 元信息（目标词出现数、测验题数、最好成绩、已听/未读状态）
- 游客限制：仅可阅读第 1 篇故事，其余显示「登录解锁」
- 待审批提示：已注册但未通过审批的用户看到等待提示横幅

**数据源**：`stories.json`（135 篇），按 `ch` 字段分属 22 章。

### 4.3 阅读器

**核心交互**：

| 功能 | 说明 |
|------|------|
| 目标词高亮 | `{{word}}` 标记的词渲染为绿色下划线 `.tw`，点击打开单词弹窗 |
| 非目标词可查 | 所有英文单词均可点击（`.ow`），自动词形还原后查词典 |
| 逐句译文 | 桌面端：鼠标悬停句子左侧出现「译」按钮，点击展开/收起该句中文译文 |
| 点句译文模式 | 移动端：开关按钮控制句尾「译」圆钮显隐，触摸设备首次进入自动开启 |
| 显示全部译文 | 一键展开/收起所有句子译文 |
| 点句朗读 | 点击句子本身朗读该句（读完自动停），点播放键可继续连读 |
| 上下篇导航 | 阅读头部显示「上一篇/下一篇」按钮，按当前章节筛选范围切换 |
| 阅读位置记忆 | 600ms 节流记录滚动位置，下次打开自动恢复（含图片/字体加载后三次校正） |
| 沉浸模式 | 滚动 >40px 后阅读头部收缩（`.shrunk`），侧栏隐藏 |

**单词弹窗（wpop）**：

- 内容：单词 + 英/美双音标（带发音按钮）+ 释义（多义项按语境排序）+ 例句 + 例句中文
- 语境消歧：非目标词根据所在句译文自动排序义项，命中义项内关键词高亮
- 掌握度显示：已测验的词显示当前等级（陌生/眼熟/基本掌握/牢固）+ 分数
- 收藏按钮：☆ 加入收藏生词本（自动进入间隔复习计划）
- 出现篇目：显示该词出现在哪些故事中，可点击跳转定位
- 智能定位：桌面端在词右下方弹出（超边界翻转），移动端固定底部抽屉
- 焦点管理：`role=dialog` + Tab 焦点陷阱 + 关闭后归还焦点

**朗读条（audiobar）**：

- 播放/暂停 + 停止 + 上一句/下一句
- 进度条（range slider）：显示当前句/总句数 + 预估时间
- 语速选择：0.6x / 0.75x / 0.85x / 1x / 1.15x / 1.3x
- 音色选择：☁ Azure 云端（8 种）/ ⚡ Edge 免费自然语音 / 🖥 本机语音
- 逐句高亮跟随：当前朗读句加 `.speaking` 背景高亮

**目标词速查面板（wq-panel）**：

- 右侧竖排「目标词速查」标签，点击展开/收起
- 列出本篇所有目标词：单词 + 英美音标 + 释义 + 例句
- 搜索过滤（150ms 防抖）
- 键盘导航：↑↓ 切换卡片、Enter 朗读选中、Esc 收起
- 定位按钮：点击跳转到正文中该词位置并高亮闪烁
- 滚动/朗读时自动隐藏标签，停止后浮现

**篇末测验（quiz）**：

- 每篇故事配 5–10 道选择题（题干+选项全英文，避免靠中文蒙答案）
- 选项随机打乱顺序
- 提交后显示：得分/总题数 + 百分比 + 逐题对错标记 + 中文详细解析
- 结果自动计入学习统计（答对/答错更新掌握度）
- 操作按钮：重做本篇 / 下一篇故事 / 查看学习统计
- 最好成绩记录：`S.quiz[storyId] = {attempts, best, lastTs}`

### 4.4 学习统计

**总览指标**：

- 整体掌握度（百分比）
- 目标词汇总数
- 四级分布：牢固 / 基本掌握 / 眼熟 / 陌生（+ 未测）
- 测验总次数

**掌握度算法**：

```
score = min(100, 正确次数×12 + 点查次数×3 - 错误次数×8)
等级：score≥85 牢固 | ≥65 基本掌握 | ≥40 眼熟 | <40 陌生
```

**词汇列表**：

- 筛选：按等级（四级 + 全部 + 未测）
- 搜索：按单词模糊匹配（200ms 防抖）
- 排序：掌握度最弱优先 / 最好优先 / 答错最多 / 点查最多 / 字母顺序
- 每行显示：单词 + 音标 + 进度条 + 等级标签 + 正确率 + 点查次数 + 出现篇数
- 分页加载：每次渲染 120 条，「显示更多」按钮追加
- 点击行：弹出详情弹窗（含跳转复习链接）

**近 7 天学习趋势**：柱状图显示每日学习词数。

**学习建议**：根据薄弱词数量、正确率等自动生成高/中/低优先级建议。

### 4.5 生词本与间隔复习

**生词本**：

- 来源：阅读时点击非目标词 → 弹窗中 ☆ 收藏
- 列表：按收藏时间倒序，显示单词 + 音标 + 释义 + 来源故事
- 操作：移除 / 点击来源跳转到故事定位该词
- 到期提示：显示「N 个已到期」或「下次复习时间」

**艾宾浩斯间隔复习**：

- 复习间隔：5分钟 → 30分钟 → 12小时 → 1天 → 3天 → 7天 → 15天 → 30天
- 卡片式交互：先显示单词 → 点击「显示答案」→ 揭示释义+音标+例句 → 选择「认识/不认识」
- 认识：进入下一间隔阶段
- 不认识：重置为 5 分钟后再次到期，本轮末尾重新出现
- 进度显示：N/总数 · 认识 X · 不认识 Y
- 键盘快捷键：Space 揭示 / → 认识 / ← 不认识
- 完成页：统计本轮结果 + 提示不认识的词 5 分钟后再来

**导出**：

- CSV 格式（word, phonetic, definition, source）
- TXT 纯文本（word - definition）
- Anki 制表符分隔（word\tdefinition）

### 4.6 随身听（文章连播）

独立于阅读页朗读条的全局连播系统，右下角入口：

**入口形态**：

- 未播放：右下角固定圆形玻璃按钮（耳机图标），hover 显示断点信息
- 播放中：旋转封面悬浮球（章节号 + 标题首字母/封面图），附暂停/停止按钮
- 点击悬浮球：打开全屏播放器浮窗

**播放器浮窗**：

- 当前文章信息：标题 + 中文副标 + 章节 + 句进度
- 正文展示：当前句高亮 + 上下文可见 + 译文（可配置）
- 播放条：播放/暂停 + 停止 + 上一句/下一句 + 进度条 + 语速 + 音色
- 设置面板（可折叠）：

| 设置项 | 选项 |
|--------|------|
| 范围 | 全部文章 / 未读 / 已读 |
| 顺序 | 顺序连播 / 随机 |
| 模式 | 纯英文 / 英中对照 |
| 循环 | 列表循环 / 单篇循环 / 播完即停 |
| 句间停顿 | 0 / 0.5s / 1s / 2s |
| 报篇名 | 开 / 关 |
| 定时 | 不定时 / 播完本篇 / 15/30/45/60 分钟 |

**播放状态机**：`title → (en → tr?)* → 篇尾 → 下一篇/循环/停止`

**锁屏/后台续播**：

- Media Session API：标题=当前句前 80 字，artist=IELTS Vocab，系统控件可 play/pause/prev/next
- Screen Wake Lock：防熄屏中断
- 回前台自动检测并续播
- iOS 保活：每 5s pause()+resume() 踢一脚
- 云端音频 1s interval 监控暂停并自动 resume

**断点续听**：`S.listen = {sid, sen, cfg}` 持久化到 localStorage，下次打开自动恢复。

### 4.7 账号与数据管理（「我的」视图）

**账号系统**：

- 游客模式：数据仅本地，可阅读第 1 篇
- 注册：邮箱 + 密码（≥6位），注册后角色为 pending，需管理员审批
- 登录：邮箱 + 密码，登录后自动拉取云端数据
- 审批机制：pending 用户每 60s 轮询角色变化，通过后自动解锁
- 退出登录：切回游客数据（不丢失）

**云同步**：

- 同步内容：阅读进度、掌握度统计、测验记录、生词本、复习计划
- 冲突策略：时间戳新者胜
- 推送时机：每次 `save()` 后 debounce 推送
- 拉取时机：登录成功 / 手动点击「立即同步」
- 离线容错：断网时本地正常使用，联网后自动补传

**数据备份**：

- 导出：JSON 格式完整备份（含全部学习状态）
- 导入：选择备份文件恢复（覆盖确认）
- 重置：清空全部学习数据（二次确认）

**学习分析面板**：

- 四格指标：目标词汇数 / 已学习 / 测验正确率 / 牢固掌握

### 5.9 学习计划与任务模式（第一期已实现，尚未合并上线）

> 详细规格与决策过程见 `docs/2026-09-20-学习计划与任务模式重设计-PRD.md`；

**记忆模型：账记在词上，不记在句上**

| 项 | 口径 |
|---|---|
| 五态 | `fresh 陌生 → seen 已见面 → recognized 文中可辨 → owned 义项直连 → graduated 已毕业` |
| 接触是货币 | 完整跟读一句 = 句内**每个**未毕业目标词各 +1 接触；读句子本身就是背单词 |
| 接触去重 | 键 = `词 + 句 + 日`，同一天反复回放同一句只算一次（毕业不能被一句刷出来） |
| 检索只升级 | 答对才推进状态；**答错不倒退**，只把 `due` 拉回今天 + 错误计数 +1 |
| 两个语境 | 课文句 + 卡上例句 `ex` 各答对一次才算 `recognized`；例句题在 ② 末尾补 |
| 重点词 | 连错 3 次标 `leech`，只加密度、**永不隐藏** |
| 间隔表 | `WORD_INTERVALS`（20 档）+ 毕业后 `[14, 30]` 天；`reps ≥ 20` 且 `ok3 ≥ 1` 才毕业 |

**真值只有一份**

| 项 | 口径 |
|---|---|
| 存储 | `localStorage['ielts.shadow.v2']`，其中 `events[]` 是**只追加**事实流 |
| 派生数 | 计划、进度、连续天数、词状态一律由 `ShadowPlan.replay(events)` 现算 |
| 禁止 | 不存 `debt/owed/backlog` 等欠账字段；不在两处算同一个数 |
| 事件 | `contact / quiz / promote / flag / dayplan / relearn`，`id` 为内容哈希 → 重放幂等 |

**排程与预算**

| 项 | 口径 |
|---|---|
| 唯一输入 | 每天有多少分钟（5–180）。**没有**总天数、没有慢/正常/快三档 |
| 三池 | A 到期复习 → C 新词 → B 深化；预算花完就停 |
| 预留成本 | 每句按 `句时 + 2×6s 题` 预留，例句题再扣 `6s` ⇒ `usedSec ≤ 预算` 由构造保证 |
| 不生成欠账 | 断更 N 天回来，今天的量还是分钟数说了算；没读的词永远留在池子里 |
| 地板 | 空队列时保底给 1 句 + 1 题，保连续天数，但不装作今天很充实 |
| 日界 | 默认凌晨 4 点算换一天（可设 0/2/3/4/5/6）；`dayKey(ts, boundaryHour)` |
| 句数承诺 | 每天第一次算出的队列规模**钉住不涨**（滚动队列会不断补新句，分母跟着涨就是目标被偷偷抬高） |

**任务模式：成块的三遍**

| 遍 | 做什么 | 遮什么 | 记账 |
|---|---|---|---|
| ① 通读 | 这批句子按原播放链完整跟读，倍速/A-B/逐句重听照旧 | 不遮 | 每个未毕业词 +1 接触 |
| ② 挖空 | 每句遮 1 个目标词 + 末尾例句题 | 遮**英文**（保留词长） | 答对 → 该语境 +1 |
| ③ 选义 | 英文照显、高亮该词，选它**在这一句里**的意思 | 遮**中文义项** | 答对 → `recognized→owned` |

- 批次在 ① 开始那一刻**快照**：队列是滚动的，不快照就会发现 ② 无题可出。
- 每遍之间弹**遍间小结**（三个数字，且只在这里出现一次）。
- ② 做题态播放条让位（这条态的控件是选项 / 回看句子 / 这题有问题）；① 态上一句/下一句/再来**全部常驻**。

**出题与降级**

| 项 | 口径 |
|---|---|
| 合法空格 | 只有 `[[key:display]]` 标记里的词能当空格；遮 `display`、判 `key`；**永不遮词伙** |
| 四层闸门 | L1 卡上「同义词：」黑名单 → L2 词性句法 → L3 当前语境唯一性 → L4 同语义场 |
| 出口 | 干净干扰项 < 3 → 降级**回忆题**（中文 + 首字母 + 词长 + 词伙首词），判分容忍编辑距离 ≤1 |
| ③ 出不干净 | 直接跳过这道题（不在 ③ 里默写拼写） |
| 确定性 | 选项顺序 `seed = hash(句 + 词 + 日)`，同一天重进不重排 |
| 这题有问题 | 每题一个 `flag` 按钮，记事件、立即停用，等人工裁决 |

**界面（数字唯一性）**

| 数字 | 唯一的家 |
|---|---|
| 今日进度 `n/N` | 任务栏（面板打开时同一条口径） |
| 预计剩余 | 任务栏，仅 ① 态 |
| 今天晋升词数 | 遍间小结 + 面板栏 2 |
| 「X 轮」「已读 x/1833」 | **已删除**，不再有"读完一轮"这种全局承诺 |

面板三视图：**今天**（两栏并列、永不合并成一个总数）· **计划**（只有分钟 + 日界 + 是否见新词 + 备份）· **词本**（按状态筛选、可手动重学）。

**云同步**：只把 `events` 上传到 Supabase `shadow_events`（建表脚本 `sql/shadow_events.sql`，需人工执行）。
无 update、无合并策略，靠 `(user_id, event_id)` 主键去重；上传失败只在原地挂一条常驻提示，不弹窗、不打断跟读。

## 9. 语音合成系统

### 9.1 三级音色架构

| 级别 | 来源 | 音质 | 要求 |
|------|------|------|------|
| ☁ Azure 云端 | Supabase Edge Function → Azure Speech | ★★★ 最自然 | 登录 + admin 配置密钥 |
| ⚡ Edge 免费 | Edge 浏览器内置 Online Natural 语音 | ★★★ | 用 Edge 打开 |
| 🖥 本机 | 浏览器 speechSynthesis API | ★~★★ | 无 |

### 9.2 Azure 云端音色清单

| 口音 | 音色 | 性别 |
|------|------|------|
| 英式 en-GB | SoniaNeural | 女 |
| 英式 en-GB | LibbyNeural | 女 |
| 英式 en-GB | RyanNeural | 男 |
| 英式 en-GB | ThomasNeural | 男 |
| 美式 en-US | AriaNeural | 女 |
| 美式 en-US | JennyNeural | 女 |
| 美式 en-US | GuyNeural | 男 |
| 美式 en-US | AndrewNeural | 男 |

默认音色：`en-GB-SoniaNeural`

### 9.3 合成管线

```
用户触发 → 串行请求队列（150ms 间隔）→ 三级缓存查找
  ├─ 命中内存 Map（≤120 条 blob URL，LRU 淘汰）→ 直接播放
  ├─ 命中 IndexedDB（iel-audio/clips，持久跨会话）→ 加载到内存 → 播放
  └─ 未命中 → POST /functions/v1/tts {text, voice, rate}
       ├─ 成功 → blob URL → 写入两级缓存 → 播放
       └─ 失败 → 600ms 后重试一次 → 仍失败 → 降级本机语音
```

缓存 key：`r2|voiceId|rate|text`

### 9.4 预取策略

- 主站随身听：当前句 + 下一句预取
- 跟读应用：8 句预取（≈40-80s 缓冲），锁屏后台被节流时仍无缝续播
- 循环/AB 模式：只发单句链（预取会打乱循环计数）

### 9.5 错误处理与降级

| 错误码 | 含义 | 用户提示 |
|--------|------|---------|
| 403 forbidden | 需账号审批 | "请先等待管理员审批" |
| 401 | 未登录/token过期 | "请先登录" |
| 503 | 未配置 | "云端语音暂未开放" |
| 403 | Azure 密钥无效 | "Azure 密钥无效或区域不匹配" |
| 429 | 配额用尽 | "请求频繁或配额用尽" |

降级链：云端失败 → 本机语音继续 + toast 提示（30s 内不重复）
