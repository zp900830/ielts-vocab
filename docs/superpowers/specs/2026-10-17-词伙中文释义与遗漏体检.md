# 2026-10-17 词伙补中文释义 + 遗漏体检

## 一、这次改了什么

句下词卡与随身听课卡的「词伙」行，从纯英文变成「英文搭配（中文释义）」：

```
词伙：dark cellar（黑暗的地窖）
词伙：lively atmosphere（热闹的气氛）, build up in the atmosphere（聚集在大气中）, atmosphere in the workplace（工作环境）
```

- 数据层：`data/vocab.json` 的 `note` 字符串，「词伙：」这一段逐条追加全角括注；`同义词：` 段与 `；同义词：` 尾巴一字不动。
- 显示层：`index.html` 的 `noteRestHtml()` 把中文括注包进 `.nb-zh`（透明度 .68），跟英文搭配分层；`noteBar()` 与 `listenCardNote()` 共用。

## 二、译文从哪来（重要事实）

用户给的是 **3.0 版**（291 页，33 天话题版）。实扫后确认：

- 3.0 **没有** 2.0 那种「全书词伙分类列表」附录；附录只有口语心得、时态、Part2 思路三篇。正文是「中文思路 ↔ 词伙」两栏表格，逐条对照都在表格里，OCR 跨栏后行序会乱，不能直接当词典用。
- 仓库里 2.0 的 OCR 全文 `work/ref/gjb_book.txt` 里，附录1（p.198–220）是干净的逐行「英文搭配 中文释义」：1582 非空行，英文+中文同行 1210 行（76.5%），其余是话题标题与被 OCR 挤到下一行的断对。
- 本项目 3237 条词伙里，能在 2.0 附录1 精确对上的只有 **222 条（7.3%）**；文章里的词伙绝大多数是按课文句子生成的（`hot mantle`、`grey granite`、`dark cellar`），不在任何雅思词伙书里。

所以最终口径：

| 来源 | 条数 | 说明 |
|---|---|---|
| PDF 书里的中文 | 222 | 逐字沿用，含少量书本身的意译（如 `strong appetite 需求很高`） |
| 无书可查，按课文语境手译 | 2831 | 与书同风格：名词短语/动宾短语，2–14 字 |
| 合计 | 3053 唯一搭配（3237 词条引用） | 全部有中文，无空缺 |

顺手修掉 4 条明显 OCR/释义错字：`稳足的收入`→稳定、`买际工作的能力`→实际、`锻燒`→锻炼、`pop singers 摇滚歌手`→流行歌手（书里写错）。

## 三、遗漏体检结果

判定口径：目标词在课文里出现、但整张卡没有「词伙：」段 = 整条缺失。

- 课文里出现的目标词（去重）**3244**，其中 **831 个（25.6%）** 没有词伙。
- 这 831 个里 **801 个只在课文出现 1 次**，基本是各篇的补充词：`oxygen / hydrosphere / lithosphere / oxide / glacier / pebble / quartz / tsunami …`
- 在这 831 个词里，2.0 书里能查到搭配的只有 **2 个**（`happen`、`exhaust`）——**PDF 侧补不了这个洞**。
- 机器按「adj+名词 / 名词+名词」从原句抽，只能抽出 **195 条**候选；人工抽查约一半不成立（`accompany lin`、`every antibiotic`、`stately cock`、`plural pears`）。
- 另有一类反向问题：**868 张卡**的词伙在全书 1833 句里一次都没出现（如 `atmosphere in the workplace`、`biological disaster`），是从书里搬来的通用搭配，不是这一句的用法。

结论：词伙不是「从 PDF 提取进文章」的产物，缺口在文章侧，不在 PDF 侧；按机器口径硬补会往词卡里灌垃圾，所以**这次没有批量写入**。待定口径：

1. **只补干净搭配**：人工从 195 条候选里挑（预计 35–50 条），只补「修饰语是实词、搭配成立」的。
2. **831 全补**：逐词读原句手写，量大，且 `hydrosphere / oxide / equator` 这类词在句子里确实没有像样搭配。
3. **补「本句用法」**：不动 831，改给 868 张「词伙不在课文里」的卡加一条原文搭配。
