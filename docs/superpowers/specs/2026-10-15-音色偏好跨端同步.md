# 音色偏好跨端同步（2026-10-15 用户报「换设备记住音色」）开发交接单

> 用户原话：「我希望已经选定的音色。在刷新或者换设备后记住之前的选择结果，不要都进入
> 二级播放页了，才发现音色不对。」分支 `agent/workbuddy-voice-memory-1015`，
> 改 `index.html` + 新增 `playwright-tests/journeys/app3/voice-sync.spec.ts`。

## 1. 病根（实测）

- **同端刷新其实没丢**：`ielts-voice`（localStorage）恢复链路正常（探针实测：选中 →
  刷新 → 标签/选择态都对）。真正缺的是**跨端**。
- 新设备（含本次电脑重置后）：localStorage 空 → 静默自动挑默认音色（实测新设备进
  随身听直接播了英式男声 Daniel，而不是用户先前选的），且自动挑的结果**不落盘**。
- 旧版记录只存本机 `voiceURI`，没存「这是哪款音色」——就算把 URI 同步过去，换平台
  也对不上（同名音色在不同平台 URI 不同）。
- 云同步已有三通道（书签+进度 / 按篇账 / 事件流），唯独没有音色。

## 2. 修法

### 2.1 可携带记录 `ielts-voice-meta = {uri, name, lang, ts}`

- `name/lang`：跨端身份（voiceURI 各平台各写各的；云端音色 `cloud:<id>` 本身稳定，
  name 存 id）；`ts`：本次选择的时刻，多端合并用。
- **迁移**：旧版裸 `ielts-voice` 在首次加载补记一条（ts=此刻，视为当前意图）；
  音色名单还没就绪（拿不到名字）时先不写、下次 `loadVoices` 重试。

### 2.2 快照事件 `voice-pref`（复用 `shadow_events`，不动表结构）

- payload `{type:'voice-pref', ts, accent, uri, name, lang}`；event_id = `vp-`+内容指纹
  （同内容重推幂等，`ignoreDuplicates` 原样跳过）——与 `article-account` 同一守则。
- **合并语义 = 最新一次选择赢**：对端 ts 新 → 静默套用（不试听、不打断播放）；
  本机 ts 新 → 补推让对端跟上；相等 → 不动。
- 拉取入口：`CLOUD.boot`（启动）/ `TASK.cloudSync`（登录即拉、回前台 30s 节流、断网恢复）。
- 推送入口：`pickVoice` / `setAccent`（口音同属音色配置）→ 2s debounce。

### 2.3 落地方向两级解析（`resolvePortableVoice` + `rehydrateVoicePick`）

原 URI → 名字+口音 → 只认名字；云 id 直接用。本机暂时没有这款（换平台 / 音色列表
异步就绪）→ 先留悬空选择，`loadVoices` 每次按名字再对齐一次；播放回退链兜底——
**选择绝不丢**（与「用户选择神圣不可侵犯」同一红线）。

### 2.4 事件流防污染 / 登出

- `cloudPull` 把 `article-account` 与 `voice-pref` 挡在 `ROOT2.events` 之外
  （与 7246 行那份守则同口径：快照型辅助通道不占事件流上限、不重推）。
- 登出清云音色时 `ielts-voice-meta` 一并清；重新登录由云同步拉回（顺带修好了
  「登出再登录云音色丢失」的老毛病）。

## 3. 回归锁（`voice-sync.spec.ts`，6 用例）

1. 选定音色：meta 落 name/lang/ts，登录态下 2s 内推 `voice-pref`（含 row 形状、`vp-` 前缀）；
2. 换设备（名字对齐）：对端裸名 `Samantha` → 本机 `fake-us-1`；口音跟随；**ts 沿用对端**；
   且套用后不回声（不再推一条）；
3. 换设备（云音色）：`cloud:` 记录直接落地；
4. 本机更新者胜：对端旧记录不覆盖本机 + 本机选择补推；
5. 迁移：旧版裸 `ielts-voice` 加载后自动补 meta；
6. 刷新后不丢：重载再进随身听，播放用的还是选定音色（真链路）。

- **反向验证（已做）**：A) 禁用套用（`if (false && best.ts > localTs)`）→ 用例 2/3 红；
  B) 禁用 `pickVoice` 的记录+推送 → 用例 1 红；恢复后 `index.html` sha 一致
  （`18cade1128e3…`）。
- 全量：**Playwright 313 passed**（307 基线 + 新增 6）；`validate_data.py` PASSED
  （未动数据，`SHADOW_DATA_VER` 不变）。

## 5. 边界与已知取舍

- 同步需要登录（与书签/进度同口径）；未登录时只有本机记忆。
- 升级首次同步窗口：两端都握着「旧版无时间戳」的本地选择时，**后加载的一端断言为
  当前意图**，对端下次拉取收敛（旧选择没有 ts，无法更精确；一次性，此后全是真时间戳）。
- 本机没有目标音色时保留悬空选择（幽灵项 + 播放回退链），不做低质替代。
- 「二级播放页」不发提示音：套用一律静默，进随身听时音色已经是对的（这正是用户要的）。
