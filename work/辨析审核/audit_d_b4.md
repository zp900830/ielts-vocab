3. **`all_synonyms` 与卡面证据打架 → 以卡面为准，元数据只在「证据强度」报备，不改 worklist、不退回义项表**（判 131，以后同类照此）。事实层：`all_synonyms` 是"两卡同义词栏是否互列"的**机械位**，`false` 可能只是因为某张卡 `note` 是空串（131 的 happen 就是这样），它既**不证明**两词不同义、也**不要求**草稿写成同义。两卡 `ex`/`exZh` 同形只差动词 = 本书能给的**最强"可换"物证**，照写进"可换性 / 中文落点"那一格，标题与默认行仍按书证写。**不许**为了让元数据好看去动卡面，也不许反过来拿元数据当语义结论。
4. **邻居词（同义词栏里的第三个词）不许拉进本组；"谁认谁"本身就是一格**（判 133 disturb·interrupt 的 interfere，同类 127 的 competition、125 的 dread/fright）。成员集合由切片包 `words` 钉死（硬约束 2），扩员/换员是 worklist 生成层的事，**草稿一律不许自己并组**。未并组的邻居词的合法用法只有一个形状：出现在"介词框架 / 本段这句用的是哪个词 / 卡上同义词族"这类格子里，**逐字引书证 + 当场标明"有卡但未并组，不进成员、不计条数"**。单向互列（A 栏收 B、B 栏不收 A）不是缺陷，是该组最有信息量的那一行。
5. **课文中文把两个英文词并成一个译法 / 只给其中一个词 —— 报它，别绕它**（判 134「凯旋 vs 胜利」、135「蓝色水域领域」、133「打断 vs 打扰」、127「参加 vs 比赛」）。处置固定为三段：① 义项只留在 `sense` 槽；② 表头用"worklist 说共享 X，可本段中文只把 X 给了 A"的**引用 + 当场否定**句式（§五.11 豁免）；③ 在「证据强度」里写清半边落空，并给出不依赖该义项名的那一格硬区别。**例外**：中文确实两句都落在同一档（126 的「可怕」、128 的「动荡」、124 的「证据」、132 的「坟墓」）→ 属 §五.6 的"名副其实"，允许在表头直说，不必把话说轻。
6. **配套要求（本批 4 处 MISMATCH 全是这一类，批次 5–6 起按条自检）**：草稿里任何 **"本书没有 / 没有第二张卡提到它 / 0 引用 / 某词各有自己的卡"** 这种**关于数据存在性的断言**，与"某串是书证"同等对待 —— 必须自己 grep 过再写。本批 4 处越界均为"把没核过的存在性断言写成结论"：124 的「proof 没有第二张卡提到它」（evidence 卡同义词栏就列着 proof）、130 的「两词在别的卡 ex/note 里 0 引用」（两卡互列同义词栏）、133 的「affect/impact/influence 三词各有自己的卡」（`influence` 在 vocab 里**没有词头**）、132 的表格标题把 1349 归进段12（实为段11 末句）。**判据：反例可以查不到，但"关于有/没有"这句话本身必须查得到。**
