# 正文校对改写规范（所有 agent 必须全文遵守）

你负责一本雅思词汇速记应用里的一「篇」课文。课文由短句组成，每句内嵌若干目标词标记 `[[key:display]]`。用户投诉：**英文蹩脚、上下文不连贯（根本不像一个故事）、中文翻译和英文对不上**。你的任务是逐段校对改写，让正文读起来自然流畅、像连贯的小故事，并让中文译文忠实对应英文。

## 输入

`secN.json`（N=篇号）字段：
- `paragraphs`: 段落数组，每段是句子数组；句子含 `[[key:display]]` 标记
- `sentZh`: 与 paragraphs 逐句对应的中文译文
- `paraZh`: 每段一条的段落小结（渲染为段末 💡 行）
- `subheads`: 段落级小标题（故事分卷），**不许改**
- `declared_words`: 本章声明要教的词表，**不许以平文出现在句子里**（见硬规则 5）
- `glossary`: 本章所有目标词的词典：`m` 词义、`ex` 例句、`exZh` 例句译文、`forms_seen` 原文出现过的词形样本。改写前先读它，确保每个目标词用对词性和义项。

## 输出契约

写多个 JSON 文件到同目录，命名 `secN.rewrite.a.json`、`secN.rewrite.b.json` …（按段分批，每批 ≤ 12 段，防止文件过大）：

```json
{
  "si": N,
  "sents": {
    "0.0": {"en": "改写后的英文句子（保留 [[key:display]] 标记）", "zh": "改写后的中文译文"},
    "0.1": {"en": "...", "zh": "..."}
  },
  "paraZh": { "0": "该段小结（不带💡前缀，代码会加）" }
}
```

- `si` 必须等于篇号 N。
- `sents` 的键是 `"段号.句号"`（都从 0 起）。
- **你负责的篇里每一段每一句都必须出现在 sents 里**（包括你判断已经够好的句子——原样抄入即可），合并器会做全覆盖检查。
- `paraZh` 可选；段落故事改动大时更新，否则可省。

## 硬规则（合并器逐条机检，违反即整句拒绝回退）

1. **每句 `[[key:display]]` 的 key 序列必须与原句完全一致**：个数、顺序、key 字符串逐字节相同。不许增删、换词、调序。
2. **display（显示形）可以按新句语法屈折**（复数/时态/比较级），但必须完整放进 `[[ ]]` 内，且在去标记后的英文正文里逐字出现。禁止 `[[key:display]]s` 这种后缀漏在外面的写法。
3. **一句就是一句**：英文里除缩写点（Mr. / Ms. / Dr. 等）外不得出现「句末标点+空格+大写开头」。不写两个句子。
4. 英文里不得出现任何中文字符；中文译文必须有中文标点；中文里不得出现 `[[`。
5. **不得新引入 `declared_words` 里任何词的平文出现**（词形精确匹配，不含屈折变体；原文已有平文出现的词你可以保留或删除，但不能新增）。要提到目标词概念时，要么用标记，要么换说法。
6. 英文长度约为原句的 0.4~2.5 倍（超 2.5 倍会被告警，超 3 倍拒绝）。
7. 段落数、每段句数不许变（输出契约本身保证了这点——你只能改写已有句子）。

## 文体规则（质量所在，认真执行）

1. **段内连贯成故事**：一个段落是一个小场景。句与句之间要有自然衔接（时间/地点/人物推进、代词回指、连接词），读起来是一段连贯叙事，不是互不相干的例句堆。
2. **卷内人设连续**：各篇有既有角色（如 Leo、Bo、Mei、林老师、王叔、Anna、Lin 等）。沿用原文已有的角色名与其中文译名（利奥、波、梅、林老师、王叔、安娜、林），不新造人物。卷与卷之间按 subheads 的故事弧推进。
3. **避免句式单调**：不许连续三句以同一个主语开头（They… They… They… 是历史教训）。变换主语、句式（问句、感叹、时间状语开头、对话引用都可以）。
4. **用词难度**：除目标词外用简单词（初中~高中水平）。不堆难词，不写复杂从句嵌套。
5. **自然地道**：避免逐词硬译腔（如 "grow tall in our warm school greenhouse" 这类生硬搭配）。写母语者真会说的话，同时保持简单。
6. **目标词用法正确**：对照 glossary 里每个词的 `m`（词性+义项）和 `ex/exZh`（例句），确保目标词在新句里的用法、搭配、义项正确自然。display 屈折要地道（如 lesson → lessons）。
7. **中文译文忠实**：与英文严格对应，不添不减不歪。数字、否定、专有名词必须对上。译文通顺自然，不逐词硬译。人名音译沿用原文已有的（原译文怎么译就怎么译）。
8. **句子长度**：12~20 词左右为宜，最长别超 24 词。朗读友好。
9. **paraZh 小结**：一段 1 句话概括场景，40 字内，不带「💡」。

## 自检（每批写盘前逐句过一遍）

- key 序列与原句一致？
- display 在正文里逐字出现？
- 没有 `]][a-z]` 断标？
- 一句就是一句？
- 中文和英文严格对得上？
- 连读整段：像一个故事吗？

## 分批节奏

先读 `secN.json` 全文和 `glossary`，然后按段顺序处理：每 12 段写一个 `secN.rewrite.<字母>.json`（a、b、c…），写完一批再处理下一批。全部段完成后，用 python3 抽查 2~3 个你写过的文件确认 JSON 合法。
