## 为什么单独写一份

这块是「打开到哪、点什么、看到什么数」的全局行为，散在四个 spec 文件里。
需要一条能照着手工复述的案例：改任何一处界面口径时，先照这份走一遍，再决定动哪个断言。

## 前置

1. `{E2E_BASE_URL}/index.html`，不登录（云端用例自己塞假的 `window.supabase`）。
2. 清 `ielts.shadow.v2`、`ielts-task-plan`、`ielts-task-progress` 才是真·首启；
   只清 v2 会触发老进度迁移（那是另一条用例）。

## 主路径（手工 8 步）

1. 点顶栏「今日」→ 出现**制定计划**屏：只有一个输入「每天有多少分钟」。
   - 断言：屏上没有「总天数」「慢/正常/快」这两条旧输入。
2. 选 15 分钟 → 「今天大约 N 句 · M 题」→ 点「开始这个计划」。
3. 面板变「今天」视图：**两栏并列**（左：今天 x/y 句 + 连续 + 完成度 + 还剩；右：词汇：今天晋升 + 三档计数）。
   - 断言：两栏没有被合并成一个「总进度」环或一个总数。
   - 断言：底部一行「今天 15 分钟：还剩 N 句 · 覆盖 M 个词」+ 小字「X 个词到期 · Y 个新词进队列 · Z 题」。
4. 点「开始 · 先通读这一批」→ 进任务模式。
   - 断言（2026-09-22 他改的口径）：底部**只有通栏任务条一条**，而且条上的操作按钮**只有一行**。
     原话：「底部工具条是乱的，所有操作按钮一行展示。最重要的操作按钮在最右侧，依次往左排。」
     所以播放那组（播放·暂停 / 单句循环次数 / A-B / 倍速 / 书签）搬进**同一行**，不再单独占一行；
     「读到第 N 句 · 章节名」那格在行里没位置，**藏掉**（句序号任务条已经在说 ① 通读 0/N）。
     **没有**进度条、**没有**展开收起键、**没有**第二颗上一句/下一句。
   - 断言：从右往左的次序是 **下一句 → 再来 → 上一句 → 播放 → 退出**（量各颗按钮的水平坐标，
     且所有可见按钮的垂直中心差 < 6px —— 这就是"一行"的可测定义）。
     全页「上一句」「下一句」各只有一颗。
   - 断言：退出 `#tbExit` 常驻可点（旧版退出只能 汉堡 → 今日 → 退出任务模式 三跳），
     **且悬浮提示写着「退出任务模式」**（他 2026-09-22：「我看还有个关闭按钮，鼠标悬浮状态需要有提示」）。
     这颗只留图标：文字版 `.lbl` 用 CSS 收掉，名字由 `title` 与 `aria-label` 承担。
   - 断言：倍速 `#rateCycle` 在任务模式里**可见可点**（旧版被 CSS 藏死 = 功能丢失，别再退回去）。
   - 断言：任务栏 `① 通读 0/24 · 今天 15 分钟`；播放行标题是「读到第 N 句 · 章节名」，
     **不重复**任务栏那个 `n/N`（数字唯一性）。
     （口径出处：原型 `:248-253` + 他 2026-09-21 的缺陷报告；旧版那句「他拍板播放条不藏」在 docs/ 里查无出处，已作废。）
5. 连点「下一句」读完这批 → 弹**遍间小结**卡：三个数字（句读完了 / 个词今天见过 / 个词往前走了一步）。
   - 断言：分母不涨。读到第 10 句时仍然是 `x/24`，不会变成 `x/31`。
   - 断言：小结里没有「欠 / 待补 / 积压 / 轮」。
6. 点「开始 ② 挖空选择」→ 卡片出现：句中目标词被挖成下划线、给中文译文并把**这个位置的意思**用
   `<u>` 划出来、给 **4 个英文候选**（有且仅有一个是答案）；按 1–4 也能选。
   - 断言：② 态**那一组播放控件整组消失**（原型 :283-284 底部就只有任务条），同一行只剩「回看句子 / 跳过这题」两颗 + 退出；
     做题卡因此抬到更接近屏幕中部（390×844：旧口径 top=459 → 新口径 top=526）。
   - 断言：做题卡里**没有**「回看句子」这颗 —— 它唯一的家在任务条上（`#tbAgain` 在 ② 文案换成「回看句子」）；
     卡头只有「② 挖空选择」，**不带** `n/N`（今日进度只由任务栏说一次，§10.1 数字唯一性表）。
   - 断言：屏幕上找不到答案词本体（`innerText` 不含它）。
   - 打字提交：对 → 「对了。」；错 → 「正确的那一个是 …」，词的状态**不倒退**，`due` 拉回今天。
   - 断言：故意答错后任务栏出现「错 1」，进度数字没有减少。
7. 走完 ② → 小结 → 任务栏「今天完成」。**没有第三步**：
   - 断言：`todayPlan().items` 里所有题都是 `pass:2`（`pass:3` 一个都不许有）；`TASK.setPass(3)` 也被折回 ②；
     界面上（任务条 / 做题卡 / 面板三个视图）查不到「③」「第三步」「选义」字样。
   - 断言：答对一道 ② 之后该词的 `ok3` 从 0 变正（毕业凭据已搬到 ②），且答错不倒退。
   - 断言：点错的选项标红、正确的标绿。
   - 断言：出不干净四个候选的句子**直接不弹题**（该句只走 ① 通读），也不降级成默写。
   - 干扰项三档供给（PRD §7.2）：该词的已裁决辨析组 → 同段其它目标词 → **整本同词性的词**。
     第三档是 2026-09-22 复核时补的：只有前两档时全书有 188 个词（5.8%）在它们出现过的
     每一句里都凑不满四个候选（拦下它们的几乎全是词性闸，那是对的 —— 选项词性不齐，
     不看词义、光靠语法就能排掉），而这些词一旦出不了题就永远拿不到毕业凭据。
     第三档照样受词性闸与双解闸管，顺序按 `hash32(词头|候选)` 定：同词同批、换词换批。
   - 全库不变式（`plan-engine.spec.ts`，跑一次全表约十秒）：把 3245 个词逐个问一遍
     「你出现过的句子里有没有至少一处出得了题」，**出不了题的词必须 ≤ 5 个**。
     这条是给工期数字把门的：`estimateDays` 的模拟默认排进来的题都出得出来，
     两边一旦不一致，界面那句「全部过约 2028 年 6 月」就是空头承诺，而在界面上看不出来。
     当前实测只剩 `million` / `billion`（全书 `num.` 的卡太少，凑不满四个同词性选项）。
8. 走完 ② → 任务栏 `今天完成`；面板「词汇」栏的晋升数 = 这两步攒出来的。

## 事件流与断网（手工 3 步）

1. 读 3 句 → `TASK.pendingEvents().length > 0`；刷新 → 事件一条不丢，词状态一致。
2. 联网（桩）→ `cloudPush()` 返回 `sent > 0`，再推一次 `sent === 0`（靠 `event_id` 去重）。
3. 把桩设成拒绝 → 本地照常推进、事件留在待发队列、屏幕下方挂一条常驻提示（**不是弹窗**）。

## 断更 7 天（见 carryover-queue.md）

改时间戳重放后：今天的量仍由分钟数封顶；7 天前见过的词还在、`lastContactDay` 没被改写成今天；
存储里不存在 debt 形状的字段。

## 刷新时没做完 → 那一行变续读条（不弹窗）

1. 有计划、今天读了几句但没做完 → 刷新。
   - 断言：底部那一行（本来就是任务栏的位置）显示「今天的任务还没做完」+「已读 N/M 句 · 还剩 X 句」，
     两颗按钮是「今天先不做」和「接着做」；**播放条仍在，没被续读条挤掉**。
   - 断言：不是弹窗 —— 弹窗每刷一次都要点掉一次，就成了新的打断源（他 2026-09-20 明确否掉的）。
2. 点「接着做」→ 进任务模式，续读条让位给正常任务态。
3. 点「今天先不做」→ 这一行收起来；同一趟刷新不再提，换一趟也不再提（按「今天」记，隔天照常）。

## 2026-09-22 全量走查新增（5 条锁 + 探针台账）

规格：`docs/superpowers/specs/2026-09-22-任务模式走查.md`；探针：`work/task_mode_audit.mjs`
（`node work/task_mode_audit.mjs` 重出 `work/task_mode_audit_result.md`，只测量不断言）。

1. **倍速只许除一次**。打开倍速到 1.5×，比较两次今日队列长度：句子数应当只多一半左右，
   **不许接近平方（2.25 倍）**。旧写法宿主传已除过的秒数、又传 `rate` 给引擎再除一遍。
2. **② 做题中点「继续任务」不许掉回 ①**。走完 ① → 进 ②、弹出一道题，然后调 `TASK.enterTaskMode()`
   （就是今日面板那颗按钮的函数）：`pass()` 必须还是 2、题卡上的选项数量不变、
   且焦点落在卡片里（出题后要能直接键盘作答）。
3. **键盘 → 就是「下一句」**。① 通读态按 `ArrowRight`，任务栏标题里的 `n/N` 必须往前跳。
   旧写法按 → 走全局翻句，能刷完整篇而进度一动不动。
4. **「几点算换一天」选 0 点要真的生效**。`setBoundary(0)` 后 `todayPlan().stats.day`
   必须等于 `ShadowPlan.dayKey(Date.now(), 0)`。旧写法宿主到处 `boundaryHour || 4`，把合法的 0 吞回 4 点。
5. **底栏自己跟自己一致**（探针量，不在 spec 里）：`--task-bar-h` 必须等于任务条实测高度
   （窄屏 ① 态曾因工期那行字到达后不再重量而差 20px）；同步提示条离底栏 ≤ 40px
   （任务模式里播放条不显示，不能再替它让 62px）；底栏文字对比度 ≥ 4.5:1。
